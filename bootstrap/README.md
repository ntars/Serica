# 种子边界

- 主选 Go **go1.27.4**；源码 SHA-256：`73cfb8571aec0c01177687db87163d46aa20e9779672772891aa17654d9a6099`。禁止浮动版本。
- 种子只能位于本目录，按 D-0101 总代码不超过 12000 行；其依赖不得进入仓库。
- Go 只按“带 GC 的 C”使用：禁接口、泛型、goroutine、channel、反射、`init`、第三方包。cgo 仅用于登记过的系统原生 API。
- 根据 D-0026，Go 种子可临时实现 P1b 自举所需能力；这是有限过渡桥，不是产品运行时。不得引入第三方实现、外部编译器、转译/透传或 Go 产品运行时。仍须维持 Go 白名单、D-0061/D-0087/D-0101 的 12000 行上限、逐行归因、Apache-2.0 与 P3b 整体删除门。
- D-0131 的 `writeByteArray` 桥在打开目标前校验、打包运行时整数数组，复用 `filesystem.write` 与现有短写循环。行简发射器借此写出 Mach-O。复跑 `make test-p1b-native-emit`。
- `archive/prototype-3.8/` 是手册 3.8 三项选型验证的冻结归档；不得演变为种子本体。
- P3b 达到 stage2 与 stage3 四段归一化结果一致后，删除整个 `bootstrap/`。删除条件不可推迟。

## 当前状态

P0b 启动门槛已于 2026-11-20 在本机验证；源码独立性与 doctor 也在临时 Git clean checkout、最小环境变量下通过。证据见 `docs/decisions/0009-seed-language-is-go.md`。活动种子源码位于本目录根部 `*.go`；每个源码文件的实现行必须登记在 `docs/build/seed-attribution.md`。

stage0 支持 P0b 受限窗口程序、P1b 编译期常量/字符串及字符串排序条件/整数/一维数组和静态模块闭包，以及显式声明 `stdout`/`stdin` 的控制台 IO 能力子门；每个 `程序` 根以 `能力` 字符串数组声明权限，输出要求 `stdout`，`readInteger（）`/`readText（）` 要求 `stdin`；`映射置` 要求 `map.write`；`argumentCount（）`/`argumentText（）` 要求 `args`，参数下标须为 0 至 255 的编译期或运行时整数，参数文本可复制到普通动态文本变量和文本数组、参与码位长度，或未经存储直接进入拼接、切片、文本比较和成功结果载荷；`readFile` 要求 `filesystem.read`，路径可为静态文本或 `argumentText（下标）`，可把最多 16 MiB−1 字节的普通文件直接根输出或装载到动态文本变量，并在 stdout 前完成 UTF-8 校验；`writeFile` 要求 `filesystem.write`，路径可为静态文本或 `argumentText（下标）`，后者还要求 `args`，覆盖创建或截断普通文件并返回实际写入的 UTF-8 字节数；复跑 `make test-p1b-static`、`make test-p1b-modules` 与 `make test-p1b-runtime`。控制台产物直接执行 ARM64 整数表达式；整数变量支持原生运算；可变整数数组通过系统虚拟内存映射动态分配，支持 `arrayPush`、动态长度、读取、更新和边界检查；`readInteger（）` 有界读取一行整数，可写入变量/数组。`readText（）` 的直接根输出最多读取 63 个输入字节并验证 UTF-8；文本变量使用动态映射存储，最多 16 MiB−1 字节，并在完整校验后输出。`textLength（文本）` 按 Unicode 标量值计算静态或运行时文本长度，支持文本变量、直接 readText（）、参数文本及受限 textConcat/substring 结果，并可将运行时长度写入整数变量；不计字节、不合并字素簇。变量写回形式的 `textConcat（左，右）` 可拼接动态运行时文本、静态字符串及受限切片操作数；切片源可为已初始化文本变量或一层“变量 + 静态后缀”拼接结果，最多生成 16 MiB−1 字节并支持安全别名写回；直接根输出拼接仍限 63 字节，超限在输出前以非零退出；`substring（文本变量或一层 textConcat 结果，起点，终点）` 按 0 至 63 的静态或运行时整数 Unicode 码位索引切片，并执行范围检查；写回文本变量时最多保存 63 个码位（252 UTF-8 字节），根直接输出按实际字节限 63；文本变量可在 `equals`/`notEquals` 布尔条件中与变量或静态字符串按 UTF-8 字节比较。文本变量和可静态求值的字符串表达式可在条件中按 Unicode 码位排序比较，不做归一化；有符号 64 字节内容的匿名映射，并可重赋值或替换为失败，`结果值` 对失败无 stdout 传播错误码。运行时文本结果独立深复制及普通文本变量/数组元素写入已实现；表达式与块体函数可通过有界 AST 展开返回整数、文本或失败结果；无效果声明且构成递归环的纯整数函数改用真实 ARM64 调用帧，以 `x0` 至 `x7` 传参、`x0` 返回，保存帧指针、链接寄存器和 `x19`，支持自递归、互递归及 200 `跳出`/`继续`，并可按到达点声明块作用域整数局部变量、在每次迭代重新初始化，循环、分支和函数顶层还可在运行时条件命中时提前返回整数；顶层守卫未命中时继续执行后续语句，整数局部声明可在循环后按执行顺序初始化，或在顶层分支内建立不能逃逸的块作用域局部值；块体支持词法局部变量、局部赋值、若否和返回分支，条件结果分支须同型并保留失败码、惰性和效果边界，作用域逃逸与返回后语句由 S-3068

# D-0017：P1b 字符串相等与常量分支

> 当前实现状态：stage0 支持编译期字符串比较与分支选择；运行时布尔值和通用控制流仍未实现。总状态见 [全阶段清单](../roadmap/p0b-p6b.md)。

## 决策

`equals（左侧文本，右侧文本）` 比较两个字符串的 Unicode 码位序列，区分大小写、不按语言环境折叠。`ifElse（条件，真值，假值）` 根据条件选出字符串；当前唯一支持的条件是 `equals`。编译期会检查两个分支，再选出结果写入产物。

## 边界

当前两者只接收常量表达式；可使用 D-0020 的不可变常量，但不支持可变/运行时变量、运行时布尔值、逻辑组合或惰性分支。源代码应由 `punct-scan` 保证 NFC；比较不执行隐式规范化。

## 验收

`examples/p1b-string-equality.serica` 将切片结果“语言表”与同一字符串比较，并另用不相等字符串验证 `ifElse` 的两条分支；产物文本为“切片与相等通过，反例分支通过”。源码检查、构建、Mach-O/dyld 校验和产物字符串核对均通过。

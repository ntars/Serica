# D-0060 拼接结果切片作为拼接操作数

状态：已定案（运行时子门通过；P1b 阶段门仍未通过）

## 决定

`textConcat` 操作数可使用 `substring` 的结果；该切片源除 D-0058 的文本变量外，还可为一层 `textConcat（已初始化文本变量，静态文本）`。此层拼接源的结果仍受 63 字节限制。切片按 Unicode 标量值索引，索引为 0–63，最多生成 252 字节。切片操作数的临时结果保持独立，变量写回继续支持目标与来源别名，并可按 D-0056 增长至 16 MiB−1 字节。

限制切片源为一层、且内部拼接操作数不能再包含切片，避免无界递归表达式与临时空间重用。更深层次返回 `S-3013`。该策略不是一般动态文本表达式、文本数组或通用容器的实现。

# D-0205 效果语句体文本局部直接返回

状态：已定案

## 背景

D-0204 已允许效果语句体函数把 `readText（）` 保存到文本局部并包装为成功结果，但 `返回 文本。` 仍报 `S-3068`。根因是函数展开阶段在局部类型标注前判断是否保留运行时函数：旧判定只识别 `readText` 构造或运行时结果局部，看不到末次返回引用的是稍后才标注为运行时字符串的文本局部，于是错误进入纯块 lowering。

## 决定

- 效果语句体函数声明并初始化运行时文本局部后，可在末尾直接返回该局部；`readText（）` 作为初值时仍须由函数声明 `stdin`、程序根声明对应能力。
- 该路径继续使用既有 ARM64 运行时函数文本返回 ABI：`x1/x2/x3` 返回缓冲区、有效字节长度和映射容量，调用方取得所有权并按收束点释放其余文本局部。
- 函数展开的运行时函数判定改为在局部类型标注前扫描“末次返回引用由直接 `readText` 初始化的局部”，避免把已识别效果送入纯表达式 lowering。
- 该开放只覆盖末尾直接返回文本局部。文本局部进入嵌套表达式、条件、容器或递归结果 ABI 仍未开放；完整效果函数 ABI、通用容器结果载荷、容器逃逸和跨函数错误恢复仍缺失。

## 验收

- `make test-p1b-runtime` 新增 1 个实际执行用例：效果函数读取 `𠮷效果返回`，直接返回文本局部，调用方存入文本变量并根输出。
- 输入与输出逐字节一致，覆盖补充平面 UTF-8、效果文本局部初始化、直接返回、调用方所有权接管和根输出。
- 运行时门为 251 个 arm64 整数形态产物、29 个函数结果边界产物、43 个运行时文本结果产物、183 个成功文本输入、349 个编译诊断和 123 个运行时拒绝样例。
- 活动种子逐行归因后为 12499/12500 行，归因完整；C-1 为 4895/12317（39.7%）。P1b 完整阶段门仍未通过。

## 后果

效果语句体函数可直接返回刚读取的文本局部，不再被迫包装为结果。通用效果函数文本 ABI、嵌套文本返回、容器载荷、跨函数恢复和完整 IO 仍未实现；本轮不创建发布包。

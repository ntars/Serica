# D-0068 循环跳出与继续

**状态：** 子门通过（P1b 运行时控制流子门；P1b 阶段门仍未通过）。

## 决定

- 增加保留词语句 `跳出。` 与 `继续。`，不增加新标点或表达式形式。
- 两种语句只在 `凡（条件）【…】。` 的动态或编译期恒真循环体内合法；可以嵌在 `若`/`否` 块中。循环外使用由 `check` 与 `build` 返回 `S-3067`。
- `跳出` 退出最内层 `凡`；`继续` 回到最内层循环条件重新求值。嵌套循环互不影响。编译期恒假循环不生成循环体；编译期恒真循环由 `跳出` 提供可达出口。
- 条件和循环体仍按现有整数/文本条件与控制流语义检查；不新增运行时错误、IO、函数 ABI 或变量作用域。

## 验收

- [x] ARM64 原产物运行嵌套 `凡` 循环，在内层执行 `继续` 与 `跳出` 后输出 `112233`；恒真循环通过 `跳出` 正常结束并输出 `3`。
- [x] `跳出` 与 `继续` 在循环外分别被 `check` 和 `build` 以 `S-3067` 拒绝。
- [x] P0b、静态、模块、运行时、种子、doctor、许可、源码独立性与 `git diff --check` 全部通过；种子为 6359/6500 行，C-1 为 4102/5882（69.7%）。运行时门覆盖 76 个整数 Mach-O、116 个成功文本输入、93 个编译诊断和 77 个运行时拒绝样例。

复跑：`make stage0`、`make test-p0b-scope`、`make test-p1b-static`、`make test-p1b-modules`、`make test-p1b-runtime`、`make doctor`、`make license`、`./tools/check-independence source`、`git diff --check`。

此子门补齐整数/文本条件循环的局部控制转移；哈希表、结构化错误传播、一般 IO、运行时函数 ABI 与行简编译器仍缺失，P1b 阶段门不通过。

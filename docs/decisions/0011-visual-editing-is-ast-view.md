# D-0011：可视化编辑是 AST 编辑视图

## 决策

可视化属于 P6b，编辑的是与手写完全等价的 `.serica` AST；文本与视图必须双向同步，UI 复用普通结构体、列表、映射。任何可视化连接都必须生成显式能力声明，不得产出黑盒界面资源。

## 取舍

放弃独立 UI 语法、不可读二进制资源和绕过类型／能力检查的拖拽捷径；可视化不得挤占 P0b 至 P5b 主线。

## 验证

四项准入验收：导出源码后手改并回读；文本与画布双向同步；与手写代码经过相同类型和能力检查；仓库不含 `.form`、`.ui`、`.res` 界面产物。依据：手册第十一节、7.1 T-7。

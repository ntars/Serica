# D-0152 单次引用的效果函数实参

纯函数调用可以接收一个直接效果调用或显式效果函数调用作为实参，前提是目标函数只在函数体中使用该形参一次。实参在唯一的引用位置求值，调用链与程序根仍须逐层声明并授权对应效果；重复引用保留 `S-4106` 拒绝。

## 根因

有界 AST 纯函数展开会按引用位置替换实参。若效果实参被替换多次，就会重复执行输入或写入；旧实现因此把所有含效果的实参整体拒绝为 `S-4106`，即使目标函数只引用一次，也阻断了合法的嵌套调用。

## 修复

- 形参使用次数先于效果判断计算：零次仍报 `S-3065`。
- 含效果实参只在形参引用次数恰为一次时允许进入纯函数展开；两次及以上继续报 `S-4106`，错误信息给出实际引用次数。
- 行简前端把原来的引用“出现过”布尔表改为真实计数，并采用与 stage0 相同的零次优先、单次放行、多次拒绝顺序；静态求值仍不执行效果调用，合法程序交给运行时。
- 不引入隐式临时变量或新的求值顺序：效果调用在唯一形参引用位置执行。展开后的效果仍经过逐层函数声明和程序根能力复核。
- 新增直接 `readInteger` 和显式用户效果函数实参两个正例，输入 `41` 均输出 `42`；重复引用反例保持拒绝。

## 验收

`make test-p1b-runtime` 通过 185 个 arm64 整数形态产物、13 个函数结果边界产物、309 个编译诊断和 118 个运行时拒绝样例。`make test-p1b-module-const` 另有 7 个运行参照产物，覆盖直接 `readInteger`、`1+readInteger` 和显式效果函数实参，同时保留零次引用 `S-3065` 与重复引用 `S-4106` 反例及编译器自检。定向静态、模块、模块 ABI、绑定、行简原生发射、doctor、许可和源码独立性门复跑通过。`make seed-audit` 为活动种子 11939/12000 行、C-1 4880/11372（42.9%），归因完整。

## 边界

本决策不支持重复引用效果实参，不保证按调用实参列表预先求值，也不开放文本、容器或多效果实参的通用调用约定。完整求值顺序、效果函数结果 ABI 与跨函数恢复仍待后续决策，P1b 阶段门仍未通过。

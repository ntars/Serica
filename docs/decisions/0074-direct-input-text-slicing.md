# D-0074：直接文本输入切片

- 状态：已定案
- 日期：2026-11-21
- 领域：P1b 原生运行时

## 决策

允许 `substring（readText（），起点，终点）` 作为运行时文本表达式。`readText（）` 仍只读取最多 63 字节的一行，并要求根程序声明 `stdin`；切片按 Unicode 标量索引，使用既有 0–63 边界及右端不包含规则。结果可由根输出或用于有界相等/排序条件。

执行时先完整读取并验证 UTF-8，再检查切片范围，成功前不向 stdout 输出。输入过长、UTF-8 非法、终点超出输入长度或索引顺序错误均以非零退出且不输出。其他动态表达式仍依各自现有语义限制；特别是运行时文本 `ifElse` 结果仍拒绝。

## 验收

- `examples/p1b-runtime-text-read-slice.serica` 将输入 `A行简Z` 按码位索引 `[1,3)` 切出 `行简` 并输出。
- `examples/p1b-runtime-text-order-expressions.serica` 的条件切片可直接以 `readText（）` 为源，覆盖真、假排序分支。
- 运行时门另外拒绝短输入、非法 UTF-8 和超过 63 字节的输入，均在 stdout 前退出；运行时文本 `ifElse` 切片源仍由 `check`/`build` 以 `S-3042` 拒绝。
- `make test-p1b-runtime` 通过：128 个成功文本输入、94 个编译诊断和 81 个运行时拒绝样例。种子维持 6500/6500 行；P1b 阶段门仍未通过。

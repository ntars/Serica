# D-0107 块体函数内运行时整数循环

状态：已验收（P1b 子门；不代表阶段门通过）

## 决定

无效果声明且块体语句包含 `凡` 的函数不再尝试在编译期展开为无循环表达式，而是保留为运行时函数。函数继续使用最多 8 个整数寄存器参数，并在自己的 ARM64 栈帧中保存整数局部状态；循环条件、循环体赋值和最终 `返回` 直接生成本地分支、回跳和函数返回。

本子门开放以下有限形式：

- 局部整数变量声明位于第一个 `凡` 之前；循环体当前只接受对已声明参数或局部变量的整数赋值。
- 条件必须产生布尔值；编译期为真的无限条件由 `S-3068` 拒绝，编译期为假的条件可正常跳过。
- 函数块最后一条语句必须是整数 `返回`；循环体中的局部声明、嵌套控制、返回、`跳出` 和 `继续` 仍由 `S-3068` 拒绝。
- 函数不得直接或间接引入 IO、数组写入或映射写入效果；隐藏效果以 `S-4106` 拒绝。
- 参数与局部状态合计不超过 502 个 64 位栈槽。

运行时函数仍通过直接 `BL` 调用并执行 `ret` 返回。调用点可以继续使用既有整数表达式、结果变量和无 stdout 失败出口；本决定不开放文本或容器状态、跨函数结果恢复或效果函数调用帧。

## 理由

块体函数此前只支持可消解为表达式的顺序绑定、赋值和条件返回。循环会产生不可静态确定的多次状态更新，必须拥有运行时局部槽和代码内回跳。复用现有运行时函数调用帧、整数表达式生成器、比较分支和失败出口，可以单独验证循环状态而不改变参数 ABI。

## 验收

- `examples/p1b-runtime-block-loop.serica` 对输入 `10` 运行累加循环输出 `55`，对 `0` 执行零次循环输出 `0`。
- 原生门新增 5 个 ARM64 产物，覆盖单循环、零次循环、双参数阶乘状态、两个顺序循环和编译期假条件；每个产物均要求真实 `bl` 与 `ret`。
- `check` 与 `build` 的新增反例覆盖循环后或循环体内声明局部变量、循环体返回、未知赋值、非布尔条件、编译期真条件、缺少返回、隐藏输入效果和文本局部值。
- `make test-p1b-runtime` 通过 138 个 arm64 整数形态、249 个编译诊断和 116 个运行时拒绝样例。
- `make seed-audit` 通过 8747/12000 行及 C-1 5891/8376（70.3%）。
- P1b 阶段门仍未通过；循环内嵌套控制、局部声明、跳出/继续以及文本/容器/效果函数状态留待后续子门。

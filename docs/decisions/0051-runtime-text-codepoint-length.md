# D-0051：静态与运行时文本码位长度

## 决策

`textLength（文本）` 接受编译期可求值的字符串表达式，或已初始化的有界运行时文本值：文本变量、`readText（）`、`textConcat（变量，静态文本）` 和 `substring（变量或单层 textConcat 结果，索引，索引）` 的结果。返回 Unicode 标量值（码位）数量：静态输入在编译期折叠为整数，运行时输入由生成的 ARM64 循环扫描已通过 UTF-8 校验的文本缓冲区，并按非续字节计数。空文本长度为零；补充平面字符计一个码位；不做 Unicode 归一化，分解序列与预组字符长度可以不同。

运行时结果作为运行时整数表达式，可以写入并更新整数变量，也可继续进入整数运算、比较条件和切片索引。长度不是 UTF-8 字节数，也不合并组合字符或扩展字素簇。运行时组合仍受现有操作约束：拼接操作数必须是变量或静态文本，切片源必须是变量；不支持任意深度的动态文本表达式或任意长度字符串。输入与拼接结果仍受 63 字节上限约束。

## 验收

- `make test-p1b-static` 构建 `examples/p1b-string-length.serica`，通过不可变字符串常量检查静态的 `行简𠮷` 得到 3 个码位；临时非 NFC 源码验证分解序列为 2、预组字符为 1，且不归一化。
- `make test-p1b-runtime` 构建并执行变量组合和直接 `readText（）` 两个长度产物；首个产物把结果存入整数变量、赋值更新后用于运行时 `ifElse` 和 `substring` 边界，另验证长度进入整数表达式与 `textConcat`。测试覆盖 ASCII、中文、补充平面码位、分解/预组字符、混合宽度、空输入、CRLF 和 63 个 ASCII 字符；反汇编确认原生字节分类循环。
- D-0051 原始运行时验收通过 84 个成功文本输入、52 个编译诊断及 61 个运行时拒绝样例；两个长度产物都复验全部 9 类非法 UTF-8/超长输入。D-0052 扩展后，当前完整运行时门通过 92 个成功文本输入、52 个编译诊断及 67 个运行时拒绝样例。P1b 阶段门仍未通过。

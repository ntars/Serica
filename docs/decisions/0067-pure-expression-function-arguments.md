# D-0067 纯函数复合表达式实参

状态：子门通过（P1b 表达能力子门；P1b 阶段门仍未通过）

## 决定

- 用户函数实参可为完整纯表达式，包括算术、内建调用和其他用户函数调用；参数仍按原有作用域替换后进行类型检查与代码生成。
- 实参中不得直接或间接包含 `readInteger`、`readText`、`arrayPush`、`arraySet` 等效果调用，仍返回 `S-4106`。需要效果时先在调用方语句中求值并写入变量，再将变量作为纯实参。
- 每次替换深拷贝 AST 节点，避免同一实参被多次引用时共享可变切片并污染函数声明。函数体预算按替换后的 AST 节点数扣减，并继续施加 64 层展开深度、65536 节点和 256 层结构嵌套上限。
- 超预算以 `S-3063` 拒绝；不引入运行时函数 ABI、递归或闭包。
- 此决定取代 D-0064 对复合实参的限制；`S-3066` 不再用于拒绝复合表达式实参。

## 阶段影响

此门移除用户函数“实参只能为常量或引用”的限制，但不改变纯表达式函数的效果边界。完整动态类型、语句函数、运行时调用约定及 P1b 阶段出口仍未完成。

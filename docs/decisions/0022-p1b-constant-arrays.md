# D-0022：P1b 编译期不可变数组

> 当前实现状态：stage0 已通过编译期不可变数组子门；动态数组、更新与迭代仍未实现。总状态见 [全阶段清单](../roadmap/p0b-p6b.md)。

## 决策

支持 `array（元素，…）` 构造不可变、同类型的一维数组；元素类型为字符串或有符号 64 位整数。数组可作为顶层 `常量` 的值，也可直接传给数组函数。空数组因无法推断元素类型而报错；不接受混合类型或嵌套数组。

`arrayGet（数组，索引）` 以零为起点取元素，索引为编译期整数常量；越界返回 `S-3032`。`arrayLength（数组）` 返回元素数量。数组、索引与结果均在 stage0 编译期求值后进入已有表达式路径。

## 边界

本决策只建立容器类型、元素类型推断和索引语义，不实现动态分配、修改、迭代、映射/哈希表或运行时数组。这些仍是 P1b 阶段门要求；常量数组子集不构成阶段出口。

## 验收

`examples/p1b-arrays.serica` 构建结果包含“行简言表，数组通过”，覆盖字符串数组、整数数组、嵌套 `arrayGet` 与 `arrayLength`。诊断样例覆盖空数组、混合及嵌套数组、正/负越界、非数组、非整数索引、长度函数参数数量错误、非数组长度参数、取值函数参数数量错误和消费上下文错型；正例通过 Mach-O/dyld 校验。

# D-0214 文本返回借用上下文递归开放

文本所有权返回函数返回的映射缓冲区必须由调用方立即借用并释放，不能进入变量、容器或可逃逸的任意表达式。前序实现用顶层调用形态白名单判定借用消费者，导致 `若（textLength（欢迎（输入））>0）`、`ifElse（equals（欢迎（输入），『行简』），…）` 与函数体局部变量 `长度=textLength（欢迎（来源））` 这类同一调用形态只是被包在条件或局部上下文中的合法用法也被 `S-3023` 拒绝。

本决策把判定改为递归借用上下文：直接文本返回实参可出现在 `textLength`/`equals`/`notEquals` 参数位、六种文本排序比较的操作数位、`ifElse` 条件与分支、控制台 `若` 条件和函数体语句；根输出边界同样使用递归判定。判定仍拒绝裸文本返回进入 `textConcat`、容器、模块绑定或未列出的表达式，避免映射所有权逃逸。此前“函数体变量接收文本返回调用后由 `textLength` 使用”因内部 lowering 顺序报 `S-3022` 的旧拒绝样例转为执行正例；`textConcat` 嵌套拒绝保留并统一为 `S-3023`。

验收：`make test-p1b-runtime` 新增条件长度、条件相等和函数体局部借用执行用例，断言 stdout 与退出码；最小复现产物分别输出 `2`、`1`、`0` 等精确结果。`make verify` 完整门链、决策索引和逐行归因通过。该决策只开放受控借用上下文，不代表通用调用求值顺序、容器逃逸或完整 P1b 完成。

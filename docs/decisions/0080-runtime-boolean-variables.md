# D-0080：可存储运行时布尔标量

**状态：** 已采纳

## 决定

比较和逻辑表达式的运行时布尔结果可以初始化、赋值给可变标量变量，并在控制流语句中重新赋值。布尔变量可用于 `若`、`凡`、`且`、`故` 和整数 `ifElse` 条件。运行时表示复用现有整数栈槽，布尔表达式生成规范的 0 或 1；条件读取时将槽值与 0 比较。

变量类型保持稳定：整数、布尔和文本变量不能相互赋值。布尔值仍不能直接输出、参与整数运算或作为数组元素；需要整数结果的条件选择使用 `ifElse（条件，1，0）` 明确转换。输入及其他效果继续由现有根能力和函数效果规则核验。

## 理由

目前运行时比较和逻辑只可临时作为条件，程序无法把条件状态带入后续语句。复用槽位和现有短路分支可提供可变布尔状态，不引入额外运行时布局、外部依赖或隐式整数转换。布尔数组、真/假字面量、错误值传播和一般容器留在后续 P1b 工作中。

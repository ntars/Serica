# D-0041 有界运行时文本变量

状态：已落地子门；不构成 P1b 阶段门通过。

## 决定

允许顶层文本变量以无参数 `readText（）` 初始化，也可通过 `赋值 文本=readText（）。` 再读一行覆盖；输出字段可以直接引用已初始化的文本变量。每个文本变量保存最多 63 个输入字节和一个规范化 LF，另用一个 64 位值保存文本长度。CRLF 中的 CR 计入输入上限。

输入在保存长度和输出之前通过 UTF-8 标量校验。无效、截断或超长输入以非零状态退出，stdout 保持为空。每个文本变量占用 64 字节缓冲区加 8 字节长度槽，折合 9 个栈槽；与整数变量和数组元素共用 502 槽限制。

## 范围

这提供的是有界、栈分配的运行时文本变量。初始化和赋值只接受 `readText（）`；文本值只能作为最终输出，不可参与拼接、切片、比较、数组、条件或一般函数调用。没有堆分配、增长字符串、文件/进程 IO 或结构化错误传播。

## 验收

- `make test-p1b-runtime` 构建并执行两个文本变量 ARM64 产物：一个验证同一变量重新读取覆盖后输出，另一个验证多个变量拥有独立缓冲区。
- 文本变量用例覆盖中文、CRLF、63 字节边界和无效 UTF-8 重赋值；失败路径非零退出且无 stdout。
- 静态诊断拒绝整数与文本变量错型赋值，并拒绝超过 502 个等价栈槽的文本变量集合。
- 当前完整运行时门执行 68 个整数产物、1 个静态文本产物、1 个直接 `readText（）` 产物和 2 个文本变量产物；共 39 个编译诊断和 32 个运行时拒绝样例通过。
- `make seed-audit` 保持 Go 子集、逐行归因及 5000 行预算；P1b 阶段门仍未通过。

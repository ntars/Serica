# D-0016：P1b 字符串切片语义

> 历史设计与验收记录。D-0025 已撤回相关 Go 种子实现；当前 stage0 不支持字符串调用或表达式，这里的旧验收不构成当前 P1b 阶段通过证据。现状见 [全阶段清单](../roadmap/p0b-p6b.md)。

## 决策

字符串切片使用标准库函数 `substring（文本，起点，终点）`。索引以 Unicode 码位为单位，从 0 开始，起点包含、终点不包含；越界、终点早于起点或非整数表达式均产生诊断。D-0021 将索引表达式扩展为编译期有符号 64 位整数运算；最终索引仍须满足 `0 ≤ 起点 ≤ 终点 ≤ 码位数`。stage0 对常量调用求值，并把结果写入产物。

## 边界

本决策不定义 grapheme cluster 用户感知字符、动态索引或运行时字符串操作；这些留在 P1b 后续项。D-0021 的整数扩展仍仅在编译期求值，不表示运行时整数或完整整数语义。函数参数使用已冻结的全角括号与逗号，ASCII `substring` 符合标准库 API 使用英文名的规则。

## 验收

`examples/p1b-string-slice.serica` 中索引表达式 `1+1`、`2+3` 求值为 0 基半开切片 `2..5`，取出“语言表”，随后与“可运行”拼接。`serica check/build` 成功，目标文件包含结果字符串并通过 Mach-O/dyld 校验。

# D-0006：设计原点与反套壳边界

## 决策

行简为多端同步应用而生。设计优先级固定为：数据默认可序列化与同步；副作用由能力声明并静态检查；UI 单线程、通过消息传递；UI 是可序列化数据；中文语法是表达媒介，不是差异点。不得把“把关键字换成中文”当成产品动机或技术差异。

## 取舍

放弃用“全中文”单独作为卖点，换取可由数据、类型、运行时与产物检验的设计目标。关键字可以与已有语言相似，但核心机制必须在相应模块通过替换测试与机器证据。

## 验证

每次声明差异特性时执行双向关键字替换测试；可视化与全中文标点不得列为独立差异点。依据：手册 1.1、1.2、第五节第一条与第八条。

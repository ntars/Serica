# D-0113 运行时文本参数相等与排序比较

状态：已验收（P1b 子门；不代表阶段门通过）

## 决定

无效果整数块体运行时函数的只读 UTF-8 文本参数可参与 `equals`、`notEquals`、`<`、`<=`、`>` 和 `>=` 比较。比较结果只能进入布尔条件、整数选择和控制流，函数返回值仍为 `x0` 整数；本子门不开放文本复制、文本返回、容器写入或结果载荷逃逸。

参数类型按证据推断：

- `textLength`、静态字符串、直接文本输入和受支持的文本构造可为参数提供文本证据。
- 一个比较操作数已有文本证据时，同一比较两侧的参数都归类为文本，因此两个文本参数可直接比较。
- 顶层真实调用实参也可证明参数为文本；这允许 `相同（左，右）` 这类只含参数相等比较的函数由 `readText`、文本变量、静态字符串或拼接结果确定 ABI。
- 整数算术、整数比较或整数相等比较提供更高优先级的整数证据，不能被一次错误文本实参反推成文本。错型仍在调用边界以 `S-3062` 拒绝。
- 无效 UTF-8 在比较和 stdout 前以非零状态退出，保持无 stdout 和无 stderr。

排序继续使用既有 Unicode 码位顺序语义，不执行 NFC/NFD 或其他规范化。补充平面 UTF-8 标量与中文文本均进入同一比较路径。

## 实现边界

语义层把有文本证据的比较参数写入运行时参数类型；后端继续使用相邻指针/长度帧槽和既有文本比较操作数装载。调用点按展平参数寄存器求值，被调函数以真实 `bl` 进入并保存自己的帧，比较后从统一收束点 `ret`。

## 验收

- `examples/p1b-runtime-text-parameter-comparison.serica` 对输入 `行简` 输出 `1001111`，组合验证参数与静态文本、两个参数、同一参数、六种相等或排序运算以及拼接结果实参。
- 自动化矩阵另覆盖静态字符串、直接 `readText`、两个运行时文本变量、拼接结果、补充平面标量和整数参数回归；文本参数产物从 7 增至 15。
- `check`/`build` 拒绝文本参数与整数排序、文本参数与整数相等以及文本参数返回，分别返回 `S-3023`、`S-3015` 和 `S-3068`；既有赋值、算术逃逸、八槽预算和隐藏 IO 反例继续通过。
- 原生产物要求真实 `bl`/`ret`；动态文本参数产物要求从 `[x19]` 参数帧装载文本槽。直接输入参数的无效 UTF-8 测试要求非零退出且 stdout 为空。

- `python3 tools/check_seed_subset.py` 与 `make seed-audit` 通过 9306/12000 行及 C-1 6038/8916（67.7%）。

# D-0045：运行时文本切片索引

## 决策

扩展 D-0044：对有界运行时文本变量调用 `substring（文本变量，起点，终点）` 时，起止索引可为整数常量、整数表达式、运行时整数变量或 `readInteger（）`。两个表达式各求值一次，按起点后终点的顺序读取。索引仍以 Unicode 码位计数，起点包含、终点不包含。

ARM64 后端运行时检查 `0 ≤ 起点 ≤ 终点 ≤ 63`。索引越界、区间反向或输入码位数不足时，在 stdout 前以非零状态退出。UTF-8 字节偏移由已验证输入逐码位扫描取得；结果可以直接输出，也可以存入有界文本变量，并保持 64 字节 scratch 下的别名安全。

## 边界

源文本仍须为已初始化的有界运行时文本变量。静态文本切片继续由编译期求值处理。运行时索引不支持布尔或文本表达式；不定义 grapheme cluster；排序比较由 D-0046 后续定义；堆分配、动态增长、容器、文件/进程 IO 或结构化错误传播。

## 验收

`make test-p1b-runtime` 实际构建并执行 5 个切片 Mach-O。动态索引产物实际从 stdin 读取两个整数并覆盖 ASCII、中文、四字节码位、空范围、63 码位上限；负起点、反向范围、超过 63 和源文本过短均无输出非零退出。另有编译期错型/常量范围诊断、Mach-O、dyld、系统符号白名单和签名检查。该子门不代表完整文本运行时或 P1b。

# D-0046：有界运行时文本排序比较

## 决策

允许两个已初始化的有界运行时文本变量在条件中使用 `<`、`<=`、`>`、`>=`，包括 `ifElse`、`若`、`凡` 及 `且`/`故` 组合。比较结果是不可存储、不可输出的运行时布尔值。

顺序按 Unicode 码位逐个比较；对已通过严格 UTF-8 校验的文本，UTF-8 字节的无符号字典序保持同一标量顺序。相同前缀时较短文本排在前面。比较不做 Unicode 归一化，不使用区域设置，也不把 grapheme cluster 合并为用户感知字符。

比较仅接受两个文本变量引用；静态字符串、文本表达式、混合类型和一般布尔表达式仍由诊断拒绝。实现扫描最多 63 个字节，不分配堆内存。

## 验收

`make test-p1b-runtime` 实际构建并执行一个包含四种关系的 ARM64 Mach-O，覆盖 ASCII 大小、前缀、空文本、中文码位、四字节码位及组合字符不归一化；反汇编核对字节比较和无符号分支。整套运行时门通过 52 个成功文本输入、51 个编译诊断及 39 个运行时拒绝样例。P1b 阶段门仍未通过。

# D-0012：语法符号与标准库命名

## 决策

语法符号按 `docs/spec/lexical.md` 冻结：中文关键字采用中性现代书面语；普通串 `『』`、原始串 `「」`、块 `【】`、句末 `。`、分隔 `，`、分组 `（）`、注释 `#`，运算符使用 ASCII。标准库 API 一律英文。语法决策必须说明相似语言、相似层次、差异及其解决的问题。

## 取舍

放弃文言语汇、缩进块、全角 ASCII 变体及全中文标准库 API，换取与文言编程的清晰边界、可见块结构和跨语言调用兼容性。全角标点只服务中文输入状态，不作为差异点。

## 验证

`punct-scan`／后续 `serica lex --stats` 检查源码 NFC、代码区半角标点与禁用字符；字符串和注释中的文本不得被错误修复。依据：手册 1.3、7.1 T-2/T-9 与第七节第六条。

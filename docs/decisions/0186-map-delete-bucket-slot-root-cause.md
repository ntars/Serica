# D-0186 整数映射删除桶槽写回根因修复

## 决策

`删映射键` 的碰撞链断链必须写回**桶槽地址本身**（8 字节桶指针槽），而不是桶节点的 `+16` 字段。

原实现把后继节点指针从节点 `+16` 读出后，写到 `x3 + 16`。`x3` 是桶槽地址（指向 24 字节桶节点），`x3 + 16` 已经越过桶槽进入下一个桶槽，等于用"后继指针"覆盖了**相邻桶**的槽位。后果：

- 单次删除即破坏相邻桶的链表头，链表遍历会解引用非法地址；
- 对同一键重复删除时，第二次删除会沿已损坏的链走，最终触发 `SIGSEGV(139)`；
- 内存布局被静默改写，属于阻断主流程的内存破坏缺陷，不能靠"缺失键不删除"的语义回避。

修复只改一处写回偏移：`storeIntegerSlot(6, 3, 16)` → `storeIntegerSlot(6, 3, 0)`。读取后继仍从节点 `+16` 取，写回目标改为桶槽 `+0`。墓哨节点的后继为 -1（无效地址），删除时必须命中墓哨分支跳过，避免把 -1 当作地址继续探测。

保持既有边界：只支持有符号 64 位整数键；墓哨键 -1 与空键不作为用户键；删除后长度减一。

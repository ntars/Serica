# D-0133 行简原生整数与布尔数组

行简为已知元素形态的可变整数数组和布尔数组分配三个栈槽，分别保存匿名映射、元素个数和容量。非空构造从左到右求值。追加耗尽容量时分配更大的映射、复制有效元素并解除旧映射。常规增长将容量加倍，接近字节数上限时改为满足本次追加的容量。

`arrayGet` 和 `arraySet` 以无符号比较检查索引，统一拒绝负数和越界值。写入在求值新元素前完成边界检查。`arrayPush` 和 `arraySet` 只能写回绑定到同一声明的拥有者，仍要求 `array.write`。编译期已知的常量数组读取可在混合整数表达式中折叠。静态条件先确定求值分支，再处理选中分支中的索引诊断。

函数帧在进入时将数组拥有者的指针槽置零。循环再次到达同一局部声明时先释放旧映射。根输出及函数返回在保留计算结果后释放本帧仍拥有的所有映射，未执行过的声明无需释放。局部数组在当前帧使用。数组形参、数组返回及动态文本数组排入后续验收。

发射器只在代码实际使用拥有型数组时加入 `_mmap`、`_munmap` 和对应 ARM64 例程。原生载荷首字节 `A` 表示数组，`B` 表示数组与整数输入。现有 `C` 和 `R` 分别表示基本控制台和整数输入。内存布局、绑定和指令仍由行简写出，系统工具执行 ad hoc 签名。活动 Go 种子为 10347/12000 行。

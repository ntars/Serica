# D-0020：P1b 不可变常量绑定与引用

## 决策

支持顶层声明 `常量 中文名=表达式。`；一份源文件可先有零个或多个常量声明，再有唯一的 `窗口=记录。` 根绑定。常量名以汉字开头，`窗口` 保留给根绑定。声明按源码顺序求值，只能引用此前声明的常量，不允许重复名或前向引用。静态类型由常量表达式推断，当前值类型为字符串或有符号 64 位整数（算术边界见 D-0021）；同类型 `+` 分别执行拼接或加法。

常量引用可出现在字符串拼接、`substring`、`equals`/`ifElse`、整数算术与位函数中。stage0 在编译期解析、检查和求值，结果再写入 Mach-O。

## 边界

这些是不可变编译期常量，不是运行时变量。当前无赋值、局部作用域、函数参数、闭包、运行时存储或跨文件名称解析。声明顺序就是查找顺序；不尝试循环依赖检测，因为前向引用直接报错。

## 验收

`examples/p1b-constants.serica` 声明字符串与整数常量，并通过引用、相等比较、常量分支、切片和嵌套位函数生成“语言表可解析”；产物通过 Mach-O/dyld 校验。`examples/diagnostics/p1b-constant-duplicate.serica` 返回 `S-3007`；前向与未定义引用返回 `S-3022`；混合类型加法返回 `S-3023`。所有源文件通过 `punct-scan`。

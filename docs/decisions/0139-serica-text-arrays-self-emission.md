# D-0139 动态文本数组与原始工具自编复验

动态文本数组为每个元素保存独立的 UTF-8 快照。索引检查有符号负值和长度上界，并向文本操作提供带长度的只读描述符。追加可增长指针表，替换先复制新值再释放旧值。数组离开函数帧或重新进入声明时释放元素和指针表。从数组读入普通变量会建立独立文本副本。

原生发射为无环包装调用传播借用文本形态，并按 4 KiB 页和页内偏移分段生成帧地址。登记的槽上限支持 4094 个槽。活动 Go 种子仍为 10347/12000 行，C-1 为 6634/9896（67.0%）。

## 验收

```sh
env GO=/Users/ntars/.local/go1.27.4/bin/go make -j1 test-p1b-native-emit
./tools/check-independence source
```

数组矩阵在 macOS arm64 验证 5 个签名产物、10 次 stage0 对照和 4 个源码拒绝。覆盖 NUL、补充平面字符、扩容、别名替换、深复制、函数帧重入和高偏移槽。4094 槽成功，4095 槽报告 S-3040。

以两份未改写入口的原始源码 `compiler/parse-expression.serica` 和 `compiler/emit-console.serica` 为输入，种子构建的一对工具和行简原生发射的一对工具输出相同的发射载荷及未签名 Mach-O。下表记录了一次可复跑的具体产物。第二对重建并签名后的工具通过 8 个分析器查询或诊断，生成并运行了一个带跨文件文本常量的新程序。编译器闭包为 11 个文件、13 条依赖边、281 个跨文件绑定。

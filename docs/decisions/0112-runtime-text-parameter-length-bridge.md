# D-0112 运行时文本参数长度桥

状态：已验收（P1b 子门；不代表阶段门通过）

## 决定

无效果整数块体运行时函数可接收 UTF-8 文本参数。首个子门只允许文本参数进入 `textLength（文本）` 及其整数结果运算，用于建立真实的跨函数文本参数 ABI；文本参数不得赋值、返回、写入容器或逃逸到不支持的操作。

参数寄存器展平后仍限最多 8 个 64 位寄存器：

- 整数参数占一个寄存器。
- 文本参数占相邻两个寄存器，依次保存数据指针和有效 UTF-8 字节长度。
- 被调函数只读文本参数，所有权仍属调用方；本子门不分配、复制或释放文本参数。
- 函数返回值仍为整数，使用 `x0`；尚未开放文本/容器返回值。

调用点的实参类型由静态语义明确确定。编译期字符串和受支持的运行时文本表达式可作为文本实参；整数表达式不得进入文本参数，文本实参也不得进入整数参数。隐藏 IO 效果继续以 `S-4106` 拒绝。

## 理由

现有运行时函数 ABI 只描述整数。直接跳向文本/容器返回会把参数传递、返回所有权、错误恢复和结果载荷同时引入，难以定位失败。先实现只读文本参数到整数结果，可独立验证参数类型注解、寄存器展平、调用点求值、被调帧保存和调用方所有权。

## 验收

- `examples/p1b-runtime-text-parameter.serica` 对输入 `甲乙` 返回 `5`（两码位加偏移 `3`）；自动化场景另覆盖静态文本、直接 `readText`、双文本参数、拼接结果参数、整数/文本/整数寄存器顺序及恰好 8 个展平寄存器。
- `check`/`build` 拒绝文本参数误传整数、运行时整数参数误传文本、五个文本参数的 10 槽预算、文本参数赋值、文本参数算术逃逸和隐藏 IO，分别稳定返回 `S-3062`、`S-3062`、`S-3062`、`S-3068`、`S-3023` 与 `S-4106`。
- 原生产物反汇编包含真实 `bl` 与 `ret`，文本参数保存为 `[x19]` 指针和 `[x19,#0x8]` 长度槽；直接 `readText` 的无效 UTF-8 以非零退出并保持 stdout 为空。
- `make test-p1b-runtime` 通过 159 个 arm64 整数形态、其中 7 个文本参数长度桥产物、270 个编译诊断和 117 个运行时拒绝样例。
- `python3 tools/check_seed_subset.py` 与 `make seed-audit` 通过 9150/12000 行及 C-1 5890/8768（67.2%）。
- P1b 阶段门仍未通过；文本参数复制、返回或容器逃逸、文本/容器返回值、效果函数帧及跨函数错误恢复留待后续子门。

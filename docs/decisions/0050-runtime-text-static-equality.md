# D-0050：运行时文本与静态字符串相等比较

## 决策

`equals（左，右）` 和 `notEquals（左，右）` 条件允许比较已初始化的有界运行时文本变量与编译期字符串；静态字符串可位于任一侧，也可引用不可变字符串常量。两侧仍按 UTF-8 字节精确比较，不执行 Unicode 归一化。运行时文本表达式仍只接受变量引用，布尔结果只能进入条件。

后端将静态字符串放在 Mach-O 常量区，使用长度检查和字节循环生成 ARM64 分支；比较不会分配运行时内存。

## 验收

`make test-p1b-runtime` 构建并执行 `examples/p1b-runtime-text-equals-static.serica`，验证静态常量位于左侧、静态字面量位于右侧，以及相等/不等、空值和 63 字节运行时输入；反汇编检查字节比较与条件分支。静态字符串与动态子串混用仍有 `S-3015` 诊断。当前运行时门通过 66 个成功文本输入、51 个编译诊断和 43 个运行时拒绝样例。P1b 阶段门仍未通过。

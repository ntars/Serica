# D-0072：运行时文本表达式相等比较

- 状态：已定案
- 日期：2026-11-21
- 领域：P1b 原生运行时

## 决策

`equals` 与 `notEquals` 的布尔条件可以比较两个同类型文本操作数，其中可包括已初始化的运行时文本变量、`readText（）`、最多四层的 `textConcat`、受支持源的 `substring`，以及运行时文本数组的 `arrayGet` 结果；另一侧也可以是编译期字符串。比较按 UTF-8 字节精确进行，不做 Unicode 归一化。

比较结果只能用于条件，不能存储或输出。`ifElse` 的运行时文本分支结果、效果调用及其他未支持的运行时表达式仍由语义检查拒绝。动态拼接的 63 字节中间结果上限、切片的既有索引边界及运行时失败必须在 stdout 输出前退出。

比较左右操作数各有独立 scratch 区；比较 scratch 放在拼接深度 scratch 之后，以免嵌套表达式覆盖输入或对侧操作数。栈帧容量按条件语句和循环中的运行时比较需求统一计算。

## 验收

- `make test-p1b-runtime` 实际执行五类文本相等比较产物，其中包括直接 `readText（）`、四层拼接、切片、运行时文本数组 `arrayGet`、相等与不等分支；总计 125 个成功文本输入、94 个编译诊断及 78 个运行时拒绝样例。
- 原生输入 `行简\n标记\n`，四层拼接与切片比较条件通过，产物输出 `42`。
- 动态文本数组经 `arrayPush` 写入运行时输入后，`arrayGet` 与目标字符串相等时输出 `42`，不等时输出 `0`。
- 静态、模块、P0b、Go 种子子集/逐行归因、许可、doctor、源码独立性及标点门均通过；种子严格为 6500/6500 行，C-1 AST 归因为 4239/6019（70.4%）。
- P1b 阶段门仍未通过。

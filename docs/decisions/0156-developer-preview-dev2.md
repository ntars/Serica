# D-0156 开发者预览 v0.1.0-dev.2 发布复验

状态：已定案

## 背景

D-0141/D-0142 建立了开发者预览源码运行时包、可选本地 prefix 安装和可复跑验收。`v0.1.0-dev.1` 之后已经合入 D-0155 及一组 P1b 效果函数结果 ABI 增量；若继续以同一版本号重建发布包，包内容与版本标识将不再一一对应。

## 决定

将开发者预览版本递增为 `v0.1.0-dev.2`，并从当前提交重新构建发布目录、压缩包、逐文件 SHA-256、SBOM、归档 SHA-256 和本地安装验收。包格式、平台、安装方式和已知边界沿用 D-0141/D-0142。

该版本仍只用于开发者验收，不表示 P1b 阶段门通过、语言完成、系统安装器就绪、Apple 公证完成或具备正式分发资格。

## 验收

- `make release` 生成 `dist/serica-v0.1.0-dev.2-macos-arm64/` 与同名 `.tar.gz`。
- `tools/test_release.py` 验证逐文件校验和、SBOM、arm64 Mach-O、签名、控制台与窗口示例构建，以及隔离 prefix 安装/卸载。
- 归档 SHA-256 写入 `dist/SHA256SUMS.archives`；该文件与构建产物位于被忽略的 `dist/`，作为外部发布资产而非源码内自引用。
- 解压归档后执行 `make verify`，并复查 `VERSION`、归档校验和、安装与卸载。

## 后果

开发者预览获得可区分的版本标识，后续语言完成度不得据版本号推断。正式发布仍受 P2b-P6b、多机验证、安装器、签名公证和法务复核阻断。

# D-0159 开发者预览 v0.1.0-dev.3 发布复验

状态：已定案

## 背景

`v0.1.0-dev.2` 之后合入了 D-0157 的直接结果观察与成功文本映射释放，以及 D-0158 的检查器迁移。功能、种子预算和发布包内容已经变化，继续用同一版本号重建会使包内容与版本标识不一致。

## 决定

将开发者预览版本递增为 `v0.1.0-dev.3`，从当前源码重新生成发布目录、压缩包、逐文件 SHA-256、SBOM、归档 SHA-256，并复跑解压后自动验收和隔离 prefix 安装/卸载。包格式、支持平台、安装方式和已知边界继续沿用 D-0141/D-0142。

该版本仍是 pre-alpha 开发者预览，不表示 P1b 阶段门通过、语言完成、系统安装器就绪、Apple 公证完成、多机验证完成或具备正式分发资格。

## 验收

- 全量源码门通过：`stage0`、P0b、P1b 静态/模块/运行时/词法/语法/绑定/模块 ABI/原生发射、`doctor`、`license` 与 `seed-audit`。
- `make test-p1b-runtime` 实测 202 个 arm64 整数形态产物、43 个运行时文本结果产物、27 个函数结果边界产物、315 个编译诊断和 118 个运行时拒绝样例。
- `make seed-audit` 报 10 个活动源码文件、11996/12000 行、归因完整；C-1 为 4850/11615（41.8%）。
- `make release` 生成 `dist/serica-v0.1.0-dev.3-macos-arm64/` 与同名 `.tar.gz`；`tools/test_release.py` 验证文件集合、逐文件摘要、SBOM、arm64 Mach-O、签名、示例构建运行和隔离安装/卸载。
- 解压归档后在独立目录执行 `make verify`；归档 SHA-256 记录在 `dist/SHA256SUMS.archives`。

## 后果

开发者预览获得可区分的版本标识。版本号只标识可验收包内容，不改变 P1b 未通过和正式发布受阻的事实。P2b-P6b、多机验证、系统安装器、Apple 签名公证与法务复核仍须另行完成。

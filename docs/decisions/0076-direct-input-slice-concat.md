# D-0076：直接输入切片作为拼接操作数

- 状态：已定案
- 日期：2026-11-21
- 领域：P1b 原生运行时

## 决策

允许 `substring（readText（），起点，终点）` 作为 `textConcat` 的一个有界运行时操作数。切片按 Unicode 标量值索引，输入最多 63 字节，索引范围保持 0–63，结果最多 252 UTF-8 字节；嵌套拼接的中间结果和根输出继续限 63 字节，顶层变量写回结果仍可增长到 16 MiB−1 字节。

读取与 UTF-8 校验、索引范围检查和拼接失败检查均在 stdout 之前完成。`stdin` 能力检查递归覆盖切片中的 `readText（）`；缺少授权时 `check` 和 `build` 拒绝。此决策不允许任意递归动态文本表达式。

## 验收

- `examples/p1b-runtime-text-concat-read-slice.serica` 读取 `A行简Z`，切取 `[1,3)`，追加“尾”并输出“行简尾”；补充平面码位边界也由原生 ARM64 实测。
- `make test-p1b-runtime` 覆盖短输入、非法 UTF-8、超过 63 字节输入的无输出失败，以及缺少根 `stdin` 时 `check`/`build` 返回 S-4102。
- 当前运行时门通过 132 个成功文本输入、95 个编译诊断和 88 个运行时拒绝样例；种子保持 6500/6500 行、C-1 为 4239/6019（70.4%）。P1b 阶段门仍未通过。

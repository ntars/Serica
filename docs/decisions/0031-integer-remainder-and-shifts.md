# D-0031：有符号整数余数与移位

> 后续演进：D-0034 扩展运行时值上的余数和移位，并加入除零、移位范围及左移溢出检查；仍不提供结构化错误值或传播。

## 决策

扩展有符号 64 位整数语法：`%` 计算向零截断除法的余数，结果符号与被除数一致；`<<` 和 `>>` 分别表示左移和算术右移。二元运算优先级从高到低为乘除余数、加减、移位；同级左结合。运算符继续使用 ASCII 符号。

移位量必须为 `0..63`，否则返回 `S-3041`。算术右移保留符号位；左移按有符号 64 位数学乘法检查结果范围，超出范围返回 `S-3018`。`%` 的除数为零返回 `S-3024`；`-9223372036854775808 % -1` 定义为 0，不产生除法溢出。

## 边界

- 这些规则用于编译期整数表达式及 P1b 控制台运行时子集。变量参与运算时仍须在当前无输入/控制流的程序中静态证明结果安全；原生产物从栈槽加载操作数并执行原生 ARM64 指令。
- 关系比较、布尔值、分支和循环不在本决策范围内；运行时余数/移位错误检查由 D-0034 扩展。
- 不改变 UTF-8、模块、自举桥、Mach-O 直接生成、依赖白名单与许可边界。

## 验收

- `examples/p1b-integer-shift-remainder.serica` 在常量表达式中组合负余数、算术右移、优先级和切片索引；`make test-p1b-static` 构建产物并检查预期文本。
- `make test-p1b-runtime` 实际执行 23 个整数 Mach-O 与 1 个 UTF-8 文本 Mach-O，反汇编断言确认 `sdiv`/`msub`、`lsl` 和 `asr` 原生指令；覆盖负值、`int64` 最小余数、变量运算和优先级。
- 15 个拒绝用例覆盖余数/除法零、移位量越界、左移溢出及原有变量边界；每项均在产物生成前返回预期诊断。
- 这仍不构成 P1b 阶段门。结构化错误值/传播、动态字符串/容器、通用 IO 和行简编译器仍待实现。

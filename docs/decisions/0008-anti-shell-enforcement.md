# D-0008：反套壳执行与产物判定

## 决策

套壳按实际产物判定。禁止关键字映射、源到源翻译、复用他语言 AST、语义透传、底层错误原文转发；禁止 parser generator、宏模拟、第三方编译器／运行时完成行简产物。唯一例外是位于 `bootstrap/`、限行、限子集、P3b 删除的 Go 种子。

## 取舍

不以“先借用、以后替换”换取短期速度。种子承担启动成本；产品编译器、运行时、标准库及工具最终须由行简实现并直接生成目标文件。

## 验证

以 `tools/check-independence source`、依赖与产物检查及阶段构建命令核对；每项外部依赖登记移除阶段与验收条件。依据：手册第五节第一至六条、4.3、4.4、附录 K。

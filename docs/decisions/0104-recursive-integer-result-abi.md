# D-0104 递归整数结果调用 ABI

状态：已验收（P1b 子门；不代表阶段门通过）

## 决定

无效果声明且构成递归环的整数函数现在可以返回有界成功或失败结果。函数调用仍使用 D-0103 的真实 ARM64 栈帧，返回值扩展为以下形式：

- `x0` 返回结果标签：`0` 表示成功，`1` 表示失败。
- 成功时 `x1` 包含整数载荷；失败时 `x1` 包含 `1..255` 错误码。
- 当前只开放整数结果载荷。文本、数组、映射、通用结果载荷和效果函数的返回值尚未进入该 ABI。

调用结果只能保存到结果变量，随后可通过 `是否失败`、`错误码` 和 `结果值` 观察或传播。编译器拒绝把结果函数隐式当作普通整数表达式，也拒绝把递归文本结果载荷混入整数结果 ABI。

## 理由

D-0103 已证明参数寄存器、返回地址、调用方保存寄存器和独立栈帧可靠。先增加固定双寄存器整数结果协议，可以单独验证函数失败返回、错误码传播和互递归结果选择；把文本指针和容器所有权同时放入 ABI 会扩大恢复与所有权问题。

## 验收

- `examples/p1b-runtime-recursive-result.serica` 对输入 `5` 输出 `15`，对 `-1` 无 stdout 退出 `31`，对 `200` 输出 `20100`。
- 原生门新增 6 个递归整数结果 ABI 产物，覆盖成功、失败、互递归的偶数/奇数结果以及无 stdout 错误码返回。
- 结果函数直接作为整数根输出、递归文本结果载荷进入整数 ABI 均由 `check`/`build` 以 `S-3023` 拒绝。
- `make test-p1b-runtime` 通过 133 个 arm64 整数形态、1 个静态 UTF-8、6 个递归整数结果 ABI 产物，覆盖 144 个成功文本输入、230 个编译诊断和 108 个运行时拒绝样例。
- 本子门没有增加运行时依赖；P1b 仍缺文本/容器/通用结果载荷与效果函数调用 ABI、块内循环和跨函数恢复。

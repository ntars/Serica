# D-0103 递归纯整数函数调用帧

状态：已验收（P1b 子门；不代表阶段门通过）

## 决定

普通纯函数继续使用有界 AST 展开。函数调用图形成递归环时，如果环中函数没有效果声明，编译器将环内函数保留为运行时函数，而不是继续内联。

运行时函数当前遵守以下 ABI：

- 最多 8 个整数参数，从左到右使用 `x0` 至 `x7` 传递；返回值使用 `x0`。
- 每个函数保存调用方的 `x29`、`x30` 和 `x19`，建立独立栈帧与参数槽，返回前恢复保存状态。
- 调用方先完整求值实参并把中间值保存到自己的栈上，再装入整数参数寄存器，以直接 `BL` 指令调用已解析的函数入口。
- 函数体和函数返回使用现有检查整数运算。算术溢出、非法除法或非法移位进入该函数所属的无 stdout 失败出口。
- 自递归、互递归和多层嵌套调用使用同一调用约定；入口先跳过函数区，函数位置和调用位移在全部代码生成完成后统一补丁。

本子门只开放纯整数递归函数。文本、布尔、数组、映射、结果载荷、效果函数和跨函数错误返回尚未进入运行时 ABI；不承诺尾调用优化或语言级递归深度上限，实际深度受进程原生栈约束。现有表达式和块体函数的非递归调用语义保持不变。

## 理由

有界 AST 展开能保持简单函数的值语义和诊断，但无法表达递归，也会让大型调用图重复生成代码。先为纯整数函数建立真实调用帧，可以独立验证参数寄存器、实参求值顺序、返回地址、被调用者保存寄存器、递归和互递归，同时避免把文本所有权、容器别名和错误载荷一次混入 ABI。

## 验收

- `examples/p1b-runtime-recursive-function.serica` 以块体 `若`/`返回` 降低后的表达式实现阶乘；对输入 `5` 输出 `120`。
- 原生门新增 6 个场景：阶乘、斐波那契、二元互递归、200 层累计、双参数乘方和引用全局常量的递归。
- 每个产物都要求反汇编包含直接 `bl` 与 `ret`，验证函数未退化为编译期完全展开；调用后的正确输出同时证明独立栈帧、被调用者保存寄存器和参数槽恢复。
- 非整数递归实参继续由 `S-3062` 拒绝；既有 228 个编译诊断和直接运行时函数入口规则无回归。
- 运行时门当前覆盖 127 个 arm64 整数形态、1 个静态 UTF-8、6 个运行时递归函数产物、144 个成功文本输入、228 个编译诊断和 108 个运行时拒绝样例。

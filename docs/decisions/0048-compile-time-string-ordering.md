# D-0048：编译期字符串排序条件

## 决策

编译期可求值的字符串表达式支持 `<`、`<=`、`>`、`>=` 条件，并可驱动静态 `ifElse` 分支及 `且`/`故` 逻辑组合。比较按 Unicode 码位顺序执行；合法 UTF-8 字节的字典序保持相同顺序。比较不做 Unicode 归一化、区域设置处理或 grapheme 合并。

该能力不放宽运行时文本排序条件的操作数约束：运行时条件仍只接受两个已初始化的文本变量引用；编译期与运行时值混用会得到类型诊断。

## 验收

`make test-p1b-static` 构建并验证 `examples/p1b-string-order.serica` 的 macOS arm64 窗口产物，静态分支结果为 `123450089`，覆盖 ASCII、相等、前缀、中文、补充平面码位、正反分支和 `且`/`故` 组合；另以非 NFC 临时源码证明 `e` 加组合重音按原始码位序列小于 `é`，产物选中“码位序列”。`make test-p1b-runtime` 继续覆盖静态文本和混合类型的运行时排序诊断。

P1b 阶段门仍未通过。

# D-0172 目录类型元数据查询边界

## 决策

新增 `isDirectory（静态文本或 argumentText 路径）`，返回整数 `1` 表示目录、`0` 表示文件或路径不存在。静态与参数路径均要求 `filesystem.read`，参数路径另要求 `args`；非法参数给 `S-3081`，缺能力给 `S-4102`，跨函数隐蔽效果给 `S-4106`。macOS arm64 后端使用 `_open`/`_fstat`/`_close`，读取 Darwin `stat.st_mode` 高字节中的 `S_IFDIR` 位；不存在路径不进入元数据分支并直接返回 `0`。前端编号 `49`，效果、类型和绑定表同步。

## 根因与修复

首次原生探针产出错误整数：分支条件误用 `b.ls`、低字节零值被错误地当作“非目录”、且缺失路径跳转曾落到函数尾之后。修复为单一位测试 `st_mode & 0x4000`，并在统一收束点分别跳到返回 `1`、返回 `0` 和函数尾部；缺失路径跳到返回 `0`。同时补上前端 `collectInputCapabilities` 的路径，否则能力门漏报 `filesystem.read`。

## 验收

`make test-p1b-runtime` 新增目录/文件/缺失三场景和静态路径产物，断言 `_open`/`_fstat`/`_close` 导入白名单及三类诊断；模块效果门覆盖共享 `filesystem.read` 能力图，模块类型门新增 `S-3081` 位置诊断。全量源码门、doctor、许可、种子审计和独立性检查复跑通过；活动种子 11860/12000 行、C-1 4794/11702（41.0%）。目录遍历、通用文件句柄、进程 IO 和完整 P1b 仍未完成。

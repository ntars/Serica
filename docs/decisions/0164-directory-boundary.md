# D-0164：目录创建与删除边界

## 背景

P1b 已有覆盖写入、追加、删除和重命名，但目录生命周期仍只能由测试脚本在 Python 中准备，语言本身无法完成安装器、缓存目录初始化和清理等基础产品闭环。

## 决定

新增 `createDirectory（路径）` 与 `removeDirectory（路径）`。成功返回整数 `0`，失败无 stdout 并以 `1` 退出；路径接受静态非空文本或 `argumentText（下标）`。两者要求 `filesystem.write`，参数路径另要求 `args`，函数内使用还要求逐层声明并传播 `filesystem.write`。macOS arm64 后端分别导入 `_mkdir` 与 `_rmdir`，前者使用 `0755` 权限。

诊断码 `S-3077` 与 `S-3078` 分别覆盖元数和路径类型错误；已知效果函数、能力声明、编译期类型和行简前端编号表同步纳入 `41`、`42`，避免再次出现 stage0 支持而自编前端未登记的分裂。

运行时门新增静态/参数路径架构检查、真实创建/删除、重复创建、删除非空目录，以及四个编译诊断样例。新增 Go 行通过移除等价空行腾挪，并同步逐行归因；种子仍低于 12000 行。

## 验证与边界

模块效果门为 7 种能力、4 个正例图、18 个位置诊断、编译器自检；模块类型门为 29 个类型查询、25 个位置诊断、3 个原生参照产物、编译器自检；运行时门为 203 个 arm64 整数形态产物、43 个运行时文本结果产物、27 个函数结果边界产物、335 个编译诊断和 122 个运行时拒绝样例。

本决定不提供目录遍历、元数据、原子替换、通用文件句柄或进程 IO，也不构成 P1b 阶段门通过。

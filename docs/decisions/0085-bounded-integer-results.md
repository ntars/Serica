# D-0085：有界整数结果与失败传播

**状态：** 已采纳

## 决定

控制台程序可构造与保存一种严格类型化的运行时结果值：

- `成功（值）` 携带一个有符号 64 位整数，标签为成功。
- `失败（错误码）` 携带一个 `1..255` 的错误码，标签为失败。
- `是否失败（结果）` 返回运行时布尔值。
- `结果值（结果）` 返回成功载荷；结果为失败时立即以携带的错误码退出，且不产生 stdout。
- `错误码（结果）` 在成功时返回 `0`，失败时返回错误码。

结果变量占用标签和值两个原生栈槽，可从另一个结果变量复制并重新赋值。结果与整数、布尔和文本保持不同类型；结果不能直接作为根输出，也不能隐式进入整数、布尔或文本表达式。静态错误码在 `check` 阶段检查，运行时错误码在产物生成后再次检查 `1..255`。

## 理由

先提供一个明确边界内的结果子门，可以验证标签、载荷、显式状态检查和失败传播，而无需同时引入通用代数数据类型、错误恢复语法或堆分配的载荷。实现复用现有整数输入、表达式、条件分支和统一失败出口，不增加系统调用、平台符号或第三方依赖。

## 边界

- 当前载荷只支持有符号 64 位整数；文本、容器、结构值和用户错误对象留在后续工作。
- 失败传播通过 `结果值` 显式触发，并不是新的异常或控制流语法。
- 失败码使用进程可观察的 `1..255` 范围；`0` 和其他整数在静态或运行时均拒绝。
- 本决定不提供错误捕获、重试、跨函数传播、通用 Result 泛型或一般 IO 错误。

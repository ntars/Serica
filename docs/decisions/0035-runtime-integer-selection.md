# D-0035：运行时整数比较与条件选择

**状态：** 已实施；P1b 子门通过。  
**日期：** 2026-11-20  
**范围：** P1b 控制台程序的整数表达式。

## 决策

`equals` 可比较两个同类型字符串或整数。字符串比较仍在编译期完成；当任一整数值来自运行时输入或整数变量栈槽时，比较在 ARM64 产物中执行。

`ifElse（条件，真值，假值）` 可在编译期选择字符串分支，也可在运行时整数比较后选择整数分支。运行时分支直接生成条件跳转，只有被选中的分支执行；分支可包含 `readInteger（）` 和 D-0034 已支持的整数运算。此项只提供整数条件表达式，不提供通用条件语句、循环、布尔变量或运行时字符串。

## 验收

- `make test-p1b-runtime` 实际执行 43 个整数 ARM64 Mach-O 和 1 个 UTF-8 文本 Mach-O。
- 可复跑变量比较和惰性分支示例：`examples/p1b-runtime-integer-selection.serica`。输入 `4\n` 输出 `-1\n`，且假分支不会读取后续输入；输入 `5\n36\n` 输出 `37\n`。
- 静态整数条件选择通过；运行时条件分别走真分支与假分支，包含从变量栈槽读取比较值。
- 未选分支含额外 `readInteger（）` 调用：回归验证它不会读取输入，也不会触发该分支中的算术失败。
- 23 个编译诊断覆盖参数数量、比较类型和分支类型错误；19 个运行时拒绝样例继续覆盖输入错误与 D-0034 算术失败。
- 所有原生产物继续通过 ARM64 反汇编、依赖/符号白名单、dyld、签名、栈槽和 502 变量边界检查。

## 影响与后续边界

`ifElse` 将运行时整数从纯算术扩展到可选结果，但尚无一般条件语句、循环和可变状态控制流。后续需要明确语句块、作用域、分支后的变量初始化状态和循环不变式，再扩展通用控制流。P1b 阶段门仍未通过。

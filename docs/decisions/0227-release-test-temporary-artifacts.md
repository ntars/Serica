# D-0227 发布验收产物隔离与清单严格核对

发布验收不再把测试生成的 `bin/console` 与 `bin/window` 写进发布目录，再对这两个路径做特殊排除和事后删除。`tools/test_release.py` 改为在系统临时目录构建并验证控制台和窗口产物，发布目录在整个验收过程中保持不变。

`SHA256SUMS` 现在必须与发布目录的全部普通文件严格一致，不再忽略已知测试产物。任何意外残留、清单缺失或摘要不匹配都直接失败。该改动只加固发布验收，不改变发布内容、语言能力或 P1b 状态。

# D-0081：可变运行时布尔数组

**状态：** 已采纳

## 决定

可变数组变量可用 `array（…）` 初始化为运行时布尔数组，并可通过 `arrayPush`、`arraySet`、`arrayGet` 和 `arrayLength` 操作。布尔数组与整数数组在语义类型上保持区分，初始化、追加和写入都必须使用布尔值；整数数组也拒绝布尔值。`arrayGet` 返回布尔类型，只能作为条件或整数 `ifElse` 的条件，不能直接输出或参与整数运算。

原生运行时复用现有按需映射的 64 位数组槽，以规范化的 0/1 表示布尔元素，不增加平台接口。追加或写入数组仍要求根程序声明 `array.write`，数组索引继续执行负值及上界检查。静态布尔数组常量、直接输出布尔值、通用容器与错误传播不在本子门范围内。

## 理由

D-0080 已为布尔标量建立稳定类型和规范化表示。动态数组复用已验收的数组存储与容量机制，能扩展这一类型而不引入隐式整数转换；类型保持在编译期验证，底层表示不会让整数值混入布尔数组。

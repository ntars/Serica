# D-0054 动态整数数组几何扩容

状态：已定案（P1b 子门；不代表阶段门通过）

扩展 D-0053：可变整数数组额外保存容量。初始化容量等于初始元素数；`arrayPush` 在 `长度 < 容量` 时直接写入现有映射，不分配、不复制。容量耗尽时优先翻倍；如果翻倍会使字节大小乘法溢出，则退回到满足本次追加所需的最小容量。扩容分配新映射，复制仍有效的元素，以旧容量解除旧映射，更新指针/容量后追加新值。

容量保持不小于长度，长度只在成功追加后增长。扩容前检查 `int64` 长度与字节数边界；映射失败或解除旧映射失败时在 stdout 前以非零退出。每次增长仍可能复制 O(n) 个元素，但连续追加的摊销复制量为 O(1)；字符串数组、哈希表和通用容器不在本决策范围。

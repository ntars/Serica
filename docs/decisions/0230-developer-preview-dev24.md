# D-0230 开发者预览 dev.24 发布包

状态：已定案

## 背景

当前树已经通过完整 `make verify`：动态环境变量名称、目录枚举、`runCommand`/`process`、九位效果传播、发布验收隔离和 225 条决策索引均有机器证据。已有 `v0.1.0-dev.23` 包早于这些改动，不能代表当前源码。

## 决策

把 `VERSION` 提升到 `v0.1.0-dev.24`，保留旧发布的目录、压缩包和归档校验和作为可追溯证据，使用当前树重新生成 macOS arm64 开发者预览包。发布文档、验收清单与 README 的版本号同步为该版本。

## 验收

- `make verify` 通过，报告种子 12875/13200、余量 325、C-1 5013/12903（38.9%），决策索引 225 条。
- `make release` 与 `make test-release` 通过。
- 发布目录内 `shasum -a 256 -c SHA256SUMS` 与 `make verify` 通过。
- 发布包内测试在系统临时目录构建产物，验收前后发布目录文件集合不变。

## 后果

该包仍是开发者预览：只有 macOS arm64 本机验证，ad-hoc 签名不构成可信分发；P1b 阶段门、安装器、公证、多机验收与法务复核仍未完成。

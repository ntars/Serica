# D-0043 有界运行时文本相等条件

状态：有限原生条件子门通过；不构成 P1b 阶段门通过。

## 决定

运行时 `equals（左，右）` 与 `notEquals（左，右）` 可比较两个已初始化的文本变量，按 UTF-8 字节逐字节相等判断。文本变量只含经 `readText（）` 校验过的 UTF-8，因此相等比较保持有效编码；比较不做 Unicode NFC 归一化。长度上限为 63 字节，比较最多检查 63 个字节。

返回的运行时布尔值只可作为 `ifElse`、`若`、`凡` 与 `且`/`故` 的条件；不能存入变量、输出或参与普通表达式。常量/字面量和文本拼接表达式不能作为运行时比较操作数；两个操作数必须是文本变量引用。整数比较保持现有语义，文本的 `<`、`>` 等排序比较当时仍不支持；D-0046 后续为有界运行时文本变量加入排序条件。

## 验收

- `make test-p1b-runtime` 构建并执行三个比较 Mach-O：`equals` 的整数 `ifElse`、`notEquals` 的 `若`、以及与 `readInteger（）` 组合的短路条件。
- 覆盖相同/不同中文、相同字节内容、空文本、不同长度与不等分支短路跳过整数读取；反汇编核对字节加载、比较和分支。
- `check` 拒绝文本/整数混型、文本变量与静态字面量混型及错误参数个数；当前整套运行时门通过 29 个成功文本输入、46 个编译诊断及 34 个运行时拒绝样例。
- `make seed-audit` 保持 Go 子集、逐行归因和 5000 行预算；P1b 阶段门仍未通过。

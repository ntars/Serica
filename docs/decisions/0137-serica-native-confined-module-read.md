# D-0137 行简项目限界模块读取

行简发射 `readModule` 与 `readModuleResult`。ARM64 例程先复核整数数组范围、路径字符、分量和 `.serica` 后缀。入口以目录标志和全路径禁符号链接选项打开项目，再将模块相对路径传给该目录描述符上的 `openat`。模块描述符通过 `fstat` 确认普通文件，通过 `F_GETPATH` 核对项目根和请求路径的实际字节。正文上限为 16 MiB−1 字节。读完关闭描述符后，使用同一个 UTF-8 验证器验证正文。

路径策略失败使用 41，文件打开、类型、读取或正文验证失败使用 42。直接读取原样传播失败状态。结果读取可检查标签和错误码，失败分支关闭仍持有的描述符并释放临时映射。模块结果重赋值转交所有权。赋给普通文本变量的成功正文采用独立副本，可以在结果被替换后继续使用。

文件系统调用的 GOT 地址按每条 ARM64 `ADRP` 所在的 4 KiB 指令页计算。带 stdin、数组及模块读取的签名产物跨过该边界，矩阵验证了跨页后仍能打开、读取、关闭和释映。

macOS arm64 实测 7 个签名产物、60 次 stage0 对照和 4 个源码拒绝。覆盖根目录与中间路径符号链接、目录和 FIFO、错误大小写、负下标、1024 字节路径上界、正文上限及超限、非法 UTF-8 和复制后的映射所有权。描述符限额为 32 的用例交替执行 80 次失败读取和 80 次成功读取。三文件探针调用实际词法器逐级发现两条导入，在叶模块读取失败时返回导入者编号、UTF-8 字节偏移和 4001 或 4002。

当前编译器闭包为 11 个文件、13 条依赖边和 260 个跨文件绑定。活动 Go 种子为 10347/12000 行，C-1 为 6634/9896（67.0%）。PART-0501 的 18 个目标串行通过，种子审计、许可、环境自检和源码级独立性检查通过。

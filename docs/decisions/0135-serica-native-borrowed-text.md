# D-0135 行简只读文本寻址与借用 ABI

`native-code` 将根输出、只读字节操作和借用调用使用的文本字面量与命名文本常量写入 Mach-O 的只读 `__TEXT,__const` 节，使用 ARM64 `ADR` 取得地址。描述符携带指针和有效字节数，末尾零字节留在常量池。输出按有效字节数写入原文，再写 LF。发射器在写出产物前检查十六进制载荷格式及寻址偏移是否落在常量池范围内。

运行时调用按实参求值顺序保留临时值，再按签名展开到 x0–x7。每个借用文本实参占连续两个寄存器，分别传递 UTF-8 指针和有效字节数。被调用者将两者保存在自己的帧中，映射由调用方原所有者负责释放。形态不符、寄存器超额及借用形参重赋值均被拒绝。只消费常量文本的原生程序可省略输入和映射系统导入。

词法对照产物使用现有 `lexer.serica` 和 `utf8.serica`，将 `lex-probe.serica` 的文件输入替换为 stdin，检查标识符、标点、整数及 EOF 的字节偏移、宽度和类型。下一步是接入命令行文本和文件读取，使用原始 `lex-probe.serica` 复验。

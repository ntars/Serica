# D-0026：受控临时自举桥

## 决策

根据项目所有者 2026-11-20 的最新指示，《行简 Serica 开发手册》作为设计方向而非不可变实施规程。实现路线可调整，但编译器自举、独立性、许可与依赖边界、原生产物和最终删除种子的核心目标不得改变。D-0025 的“禁止一切 P1b 种子扩展”不再作为当前执行约束。

允许 Go `bootstrap/` 临时实现逐项通过 P1b 所必需的编译能力，作为有限自举桥。每项扩展须对应 P1b 子门、示例和反例；不得引入第三方实现、外部编译器、转译/透传或 Go 产品运行时。编译器、运行时和标准库的正式实现仍须由 `.serica` 源组成；stage1 生成后继续推进 stage2/stage3 等价性，并在 P3b 删除整个 `bootstrap/`。

## 不变的核心验收

- P1b 只有在字符串与整数运行时、动态数组与映射、文件/进程 IO、错误传播、模块系统和编译器表达能力均有可复跑证据后才通过；编译期常量子集是中间里程碑。
- 阶段实现保持 Apache-2.0 种子许可、5000 行预算、逐行归因、无第三方依赖、源码/链接/符号/构建/环境独立性审计。
- 产物为原生可执行文件；不使用 C/LLVM/外部编译器生成行简产品代码。平台系统 API 仍按登记表和过渡档位验收。
- 每一项临时种子能力必须在行简编译器获得对应能力后由其接管；P3b 删除 `bootstrap/` 是硬门，不能延期。

## 验收与执行

- `docs/roadmap/p0b-p6b.md` 继续作为唯一阶段状态清单；P1b 子门逐项更新，禁止把当前静态语义误报为 P1b 完成。
- 种子增量只围绕 P1b/P2b 自举闭环；每轮更新 `DECISIONS.json`、种子行数/归因、依赖表和可复跑命令。
- 后续若临时种子与 Serica 正式编译器出现分歧，以独立测试集和自举产物比较找出偏差；不得靠修改验收样例掩盖。

# D-0075：直接输入作为文本拼接操作数

- 状态：已定案
- 日期：2026-11-21
- 领域：P1b 原生运行时

## 决策

允许 `textConcat（左，右）` 的任一运行时操作数直接调用 `readText（）`。每次读取仍限 63 字节，完整 UTF-8 校验通过后才参与拼接；根 `stdin` 能力检查递归覆盖该操作数。变量写回拼接继续使用动态映射，最多 16 MiB−1 字节；直接根输出拼接仍限 63 字节。

生成器已通过共用运行时文本操作数路径读取 `readText（）`；语义层现在将该操作数纳入既有有界拼接规则。输入超长或 UTF-8 非法时，程序在任何 stdout 之前以非零状态退出。未扩展到任意文本表达式或改变输入、输出上限。

## 验收

- `examples/p1b-runtime-text-concat-read.serica` 在拼接左右操作数分别读取一行，合并中文文本并原生输出。
- `make test-p1b-runtime` 覆盖两侧输入、空行、非法 UTF-8、超过 63 字节输入，以及缺少根 `stdin` 能力时 `check`/`build` 的 S-4102 诊断。
- 当前运行时门通过 130 个成功文本输入、95 个编译诊断和 85 个运行时拒绝样例；种子保持 6500/6500 行、C-1 为 4239/6019（70.4%）。P1b 阶段门仍未通过。

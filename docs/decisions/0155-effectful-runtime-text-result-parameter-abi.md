# D-0155 效果函数运行时文本结果形参 ABI

带效果的运行时函数现在可以接收、观察、转发并返回运行时文本结果形参。文本结果形参使用标签、值、UTF-8 指针和字节长度四槽 ABI；整数结果形参继续使用标签和值双槽 ABI。

## 根因

运行时形参分类此前只记录结果形参本身，没有记录调用实参携带的成功载荷形态。结果是运行时文本结果只能作为值返回或复制到本地，不能安全进入函数形参；同时内联结果操作数在参数栈准备阶段只保存标签和值，丢失文本指针与长度。

## 实现

- 函数声明保存 `parameterResultPayloads`；分类阶段扫描全部调用点，从实参推断结果形参的成功载荷是整数还是运行时文本。
- 同一结果形参同时接收整数和文本载荷时报告 `S-3062`，不静默选择其中一种 ABI。
- 文本结果形参在调用端、函数入口、参数槽、寄存器计数、偏移与字节预算、调用帧保存中均按四槽处理；整数结果形参保持双槽。
- 内联结果操作数补齐指针与长度保存，避免文本结果在被调用函数接收前退化为空值。
- 效果语句体函数可在 `是否失败` 分支中保留失败码，也可直接返回结果形参；空文本与补充平面 UTF-8 文本均保持字节长度。

## 验收

`make test-p1b-runtime` 新增 6 个 macOS arm64 场景，覆盖文本结果参数转发、失败码保留、拼接载荷、内联结果操作数、空文本和补充平面文本；直接内联文本结果参数由原 `S-3023` 拒绝改为成功运行。另新增整数/文本混合结果形参 `S-3062` 与运行时文本结果传入整数形参 `S-3023` 反例。新增成功产物各连续 8 次同路径构建并逐字节一致。

完整串行门通过 197 个 arm64 整数形态产物、25 个函数结果边界产物、315 个编译诊断和 118 个运行时拒绝样例。活动种子 11979/12000 行，C-1 为 4856/11417（42.5%），归因完整。

## 边界

本决策只开放运行时文本结果的形参传递、状态观察、原样转发和返回，不开放文本结果逃逸到普通文本变量、容器载荷、嵌套结果消费、任意效果调用求值顺序、完整跨函数错误恢复或完整 P1b。

# D-0170 开发者预览 v0.1.0-dev.9 发布复验

## 背景

D-0169 新增原子文件替换并同步前端、运行时与验收门后，开发者预览需要一个新版本标识，以便发布目录、压缩包、逐文件摘要、SBOM 和归档摘要与前一版隔离，避免覆盖既有 dev.8 证据。

## 决策

将开发者预览版本从 `v0.1.0-dev.8` 递增到 `v0.1.0-dev.9`。重新生成发布目录、压缩包、逐文件 SHA-256、SBOM 和归档 SHA-256，并在解压目录复跑自动验收与隔离 prefix 安装/卸载。包格式、平台和签名边界沿用 D-0141/D-0142。

## 边界

版本递增只标识可验收内容变化，不改变 pre-alpha、P1b 阶段门未通过、未公证、未完成多机验证和未完成正式法务复核的事实。

## 验证

源门、运行时门、模块效果/类型门、doctor、许可、种子审计和独立性检查通过；活动种子 12000/12000 行、C-1 4927/11842（41.6%）。发布目录、压缩包和归档摘要以 `make release` 产物为准。

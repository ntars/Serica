# D-0084：运行时布尔值输出

**状态：** 已采纳

## 决定

控制台根程序可以直接输出静态或运行时布尔表达式、布尔标量变量和动态布尔数组元素。外部文本表示固定为 `1` 或 `0`，分别表示真和假，并沿用整数输出的有符号十进制格式和换行规则。

## 理由

布尔值复用规范化的 64 位 `0/1` 表示。代码生成把布尔根输出显式转换为 `ifElse（条件，1，0）`，从而复用已经验证的整数输出、条件短路、变量槽和数组边界检查，不增加系统调用、平台符号或第二套格式化代码。

## 边界

- 布尔与整数仍是不同类型；本决定只开放根输出，不开放布尔算术或整数隐式转换。
- 静态布尔输出不生成运行时分派；运行时比较、布尔变量和 `arrayGet` 继续执行原有输入、短路与边界检查。
- 字符串输出规则不变，布尔值不使用 `true`、`false`、`真` 或 `假` 作为线协议。

# D-0053 运行时动态整数数组

状态：已定案（P1b 子门；不代表阶段门通过）

可变整数数组继续用 `array（…）` 初始化。原生 ARM64 产物使用 libSystem 的 `_mmap` 与 `_munmap` 按需分配匿名私有映射；数组状态保存映射地址和运行时长度。`arrayLength（数组）` 读取实时长度，`arrayGet（数组，索引）` 与 `arraySet（数组，索引，值）` 使用实时边界。语句 `赋值 数组=arrayPush（数组，值）。` 扩大映射、复制旧元素、追加新值并解除旧映射。索引/值表达式在扩容前求值，支持以同一数组的既有元素作为追加值。

本子门只支持可变整数数组；字符串数组仍为编译期不可变数组，不支持运行时更新。D-0053 的初始实现每次追加都按新长度重新映射并复制全部现有元素，复杂度为 O(n)；容量策略后由 D-0054 增补。映射失败、非法索引和算术溢出在 stdout 前以非零退出；产物只按需导入 `_mmap`/`_munmap`，不导入 malloc/realloc 或第三方运行时。内存接口属于登记的 macOS 系统 ABI，后续平台后端须使用该平台已登记的虚拟内存接口。

当前容量策略由 D-0054 增补：`arrayPush` 几何扩容，未满容量时直接写入。


为容纳这一 P1b 原生运行时子门，活动种子审计上限由 5000 行调整为 5500 行。该调整只改行数预算；Go 白名单、逐行归因、Apache-2.0、无第三方依赖、产物独立性和 P3b 删除整个 `bootstrap/` 的自举硬门继续有效。

# D-0193 开发者预览 v0.1.0-dev.20 发布复验

状态：已定案

## 背景

D-0192 开放直接和存储参数文本变量驱动的 `readEnvironment` 名称，并新增动态文本描述符安全桥；活动种子逐行归因后为 12419 行，现行预算为 12500 行。继续使用 `v0.1.0-dev.19` 重建会使包内容、验收计数和版本标识不一致。

## 决定

将开发者预览版本递增为 `v0.1.0-dev.20`，从当前源码重新生成发布目录、压缩包、逐文件 SHA-256、SBOM 和归档 SHA-256，并复跑解压后自动验收、示例构建运行与隔离 prefix 安装/卸载。包格式、macOS arm64 支持范围、安装方式和已知边界继续沿用 D-0141/D-0142。

该版本仍是 pre-alpha 开发者预览，不表示 P1b 阶段门通过、语言完成、系统安装器就绪、Apple 公证完成、多机验证完成或具备正式分发资格。

## 验收

- 全量源码门通过：stage0、P0b、P1b 静态/模块/运行时/扫描/词法/语法/绑定/导入路径/模块读取/依赖图/跨文件绑定/效果/类型/常量/ABI、doctor、license、ci-preflight 与 seed-audit。
- `make test-p1b-runtime` 实测 213 个 arm64 整数形态产物、16 个文本返回调用方存储产物、43 个运行时文本结果产物、27 个函数结果边界产物、165 个成功文本输入、349 个编译诊断和 123 个运行时拒绝样例；动态环境名称四个成功产物和非法下标诊断通过。
- `make seed-audit` 报 10 个活动源码文件、12419/12500 行、归因完整；C-1 为 4887/12235（39.9%），未触发 AST 比例复核条件。
- `make release` 生成 `dist/serica-v0.1.0-dev.20-macos-arm64/` 与同名 `.tar.gz`；发布验收验证文件集合、逐文件摘要、SBOM、arm64 Mach-O、签名、示例构建运行和隔离安装/卸载。
- 解压归档后在独立目录执行 `make verify`；归档 SHA-256 记录在 `dist/SHA256SUMS.archives`。

## 后果

开发者预览获得可区分的版本标识和可复验的动态环境变量名称能力。版本号只标识可验收包内容，不改变 P1b 未通过和正式发布受阻的事实。P2b-P6b、多机验证、系统安装器、Apple 签名公证与法务复核仍须另行完成。

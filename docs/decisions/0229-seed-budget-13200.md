# D-0229 临时自举桥预算调整为 13200 行

状态：已定案

## 背景

D-0226 的目录枚举和 D-0228 的进程命令执行都在 macOS arm64 控制台桥中新增了必要的栈帧、系统调用绑定、UTF-8 校验与失败出口。当前活动种子为 12875 个掩码代码行，超过 D-0210 的 12800 行上限 75 行；新增行均已进入逐行归因，但没有放宽任何语言子集或产品验收门。

## 决策

将 `tools/check_seed_subset.py` 的 `MAX_SEED_LINES` 由 12800 调整为 13200，仅覆盖当前已验证实现并为后续 P1b 修复保留少量空间。预算口径继续使用“掩码代码行”，逐行归因继续使用物理行范围；不改变 Go 子集、依赖白名单、许可证、源码/产物独立性、平台符号或 P3b 删除硬门。

## 验收

`make seed-audit` 必须报告 11 个活动源码文件、当前已用行数、13200 行上限、非负余量和完整归因；C-1 AST 占比若超过 40% 仍须按 D-0009/D-0059 完成语言复核。

## 后果

该调整只解决临时自举桥的必要实现预算，不表示 P1b、语言、安装器、公证或多机验收完成。后续仍应优先压缩重复指令辅助函数和可置换的原生发射层。

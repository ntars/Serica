# D-0189 映射扩容碰撞链尾提前收束根因修复

## 根因

D-0188 修复了旧桶数组探测与写入帧边界，但 `emitRuntimeMapGrow` 的碰撞链尾仍跳到重散列收束点。旧表中第一个非空桶的链迁移完后就结束整个旧表遍历，前序键没有进入新表；全量求和回归把被缺陷掩盖的 1643310 写成期望值，因此未暴露键丢失。

## 修复

- 碰撞链走完后跳到 `nextBucket`，继续遍历旧表；只有外层计数耗尽才进入收束并释放旧桶数组。
- 空桶仍跳到同一 `nextBucket`；旧桶指针/容量保存、8 字节指针槽探测、96 字节写入帧、哈希常量、节点布局和 3/4 负载策略均不变。
- 恢复 `large map rehash preserves all keys by sum` 的真实期望 1644968，并把该缺陷记录为独立决策 D-0189。

## 验证

- 增量探针：10 键、48 键、2000 键顺序插入后的全量求和分别为 90、94、1644968，长度分别为 10、48、2000。
- `make test-p1b-runtime` 通过 213 个 arm64 整数形态产物，其中 17 个映射用例；349 个编译诊断、123 个运行时拒绝样例不变。
- `make seed-audit` 报 12198/12200 行、归因完整，C-1 4834/12020（40.2%）；源码、模块、原生发射、doctor、license 与 ci-preflight 全门复跑通过。
- P1b 完整阶段门仍未通过。

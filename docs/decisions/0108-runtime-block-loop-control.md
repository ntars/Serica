# D-0108 块循环内原生控制流

状态：已验收（P1b 子门；不代表阶段门通过）

## 决定

D-0107 的无效果整数块体运行时函数扩展循环体内控制流。循环体可包含：

- 对已声明整数参数或局部状态的赋值。
- `若`/`否` 分支；两个分支都可不返回，并在分支结束后继续当前循环。
- 嵌套 `凡` 循环；每层拥有独立条件回跳与退出目标。
- `跳出。` 和 `继续。`，两者绑定最近一层包围循环。

循环控制语句仅在循环体内有效。函数块中循环外的 `跳出`/`继续` 由 `S-3068` 拒绝。循环体仍不接受局部变量声明或 `返回`；局部整数状态继续在首个循环前声明，函数最后一条语句返回整数。所有循环和分支条件必须产生布尔值，编译期为真的循环条件不能被接受，因为当前调用帧没有中断或取消协议。

隐藏 IO、数组写入和映射写入继续由 `S-4106` 拒绝。参数与局部状态合计仍不得超过 502 个 64 位栈槽。函数继续以寄存器传参、直接 `BL` 调用并执行原生 `ret`；本决定不开放文本或容器状态、效果函数调用帧、运行时文本表达式载荷或跨函数错误恢复。

## 理由

嵌套循环需要显式的循环目标栈，否则内层 `跳出`/`继续` 会错误地控制外层循环。代码生成在进入每层 `凡` 时压入条件入口和待补丁的退出跳转，离开该层时先修补内层目标，再用函数级返回补丁收束。这样可复用已有条件分支和整数表达式生成器，同时把控制流作用域限制在可通过原生产物验证的有限子集。

- `check` 与 `build` 新增循环外 `跳出`/`继续` 反例，均须返回 `S-3068`；既有循环体局部声明、循环体返回、未知赋值、非布尔条件、静态真条件、缺少返回、隐藏输入和文本局部值反例继续通过。

- `make seed-audit` 通过 8861/12000 行及 C-1 5896/8488（69.5%）。

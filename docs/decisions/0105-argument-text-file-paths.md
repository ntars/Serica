# D-0105 参数文本文件路径

状态：已验收（P1b 子门；不代表阶段门通过）

## 决定

`readFile` 和 `writeFile` 的路径参数除编译期文本外，现在接受 `argumentText（整数下标）`。参数路径复用既有 argv 边界：下标必须非负且小于实际 `argc`，扫描上限 4096 字节，并在文件打开或创建前完成 UTF-8 校验。

- `readFile（argumentText（下标））` 可读取普通文件并进入既有动态文本、长度、比较、拼接、切片、结果和输出路径。
- `writeFile（argumentText（路径下标），文本）` 可覆盖写入普通文件并返回实际 UTF-8 字节数。
- 文件路径效果仍为 `filesystem.read` 或 `filesystem.write`，参数文本效果仍为 `args`；函数须逐层声明两种效果，根程序须同时提供对应能力。
- 普通文本变量、`readText（）` 及任意其他运行时表达式仍不能充当路径。

实现文件路径指针与写入内容求值之间的寄存器冲突由临时栈槽隔离解决；路径指针在内容表达式完整求值后恢复。写入内容在创建或截断目标前完成 UTF-8 校验，失败时保留原目标。

## 理由

命令行工具需要在不引入任意动态字符串求值的前提下读取和写入用户指定路径。直接允许 `argumentText` 可在现有 4096 字节和 UTF-8 边界内实现这一需求，同时保持系统调用白名单、路径来源可审计和错误前零 stdout。

## 验收

- `examples/p1b-runtime-dynamic-file-read.serica` 以中文参数路径读取 `动态路径🙂`；`examples/p1b-runtime-dynamic-file-write.serica` 以参数路径和内容覆盖写入，返回 6 字节且文件内容无尾随零。
- 原生门执行动态路径读取和写入产物，并检查只导入该路径需要的系统符号。
- 运行时反例覆盖缺失路径参数（退出 2）、4096 字节路径（退出 3）、无效 UTF-8 路径、无效 UTF-8 写入内容，以及写入内容失败时目标文件保持不变。
- 编译反例覆盖动态路径缺少根 `args`、函数隐藏 `args`、未逐层传递效果，以及普通运行时文本不能作为路径。
- `make test-p1b-runtime` 通过 240 个编译诊断和 116 个运行时拒绝样例；`make seed-audit` 通过 8345/12000 行及 C-1 5874/7984（73.6%）。
- 本子门仍不开放任意文本表达式路径、路径规范化、目录/元数据、追加/原子替换或通用文件/进程 IO。

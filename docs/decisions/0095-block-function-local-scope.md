# D-0095 块体函数与词法局部作用域

状态：已定案（P1b 子门；不代表阶段门通过）

## 决定

用户函数除单表达式体之外，还可使用 `【】` 块体和 `返回`：

```serica
函数 修正（数值）【
变量 当前=数值*2。
若（当前>50）【
变量 超出=当前-50。
赋值 超出=超出+1。
返回 超出。
】。
赋值 当前=当前+1。
返回 当前。
】。
```

- 函数块支持局部 `变量`、对参数或局部变量执行 `赋值`、`若`/`否` 和 `返回`。
- 每个控制路径都必须返回。无 `否` 分支的 `若` 可以提前返回，其后续语句作为假分支继续执行；带 `否` 的双分支必须都返回，后续语句不可达。
- 局部名称只能引用当前作用域已声明的值。参数和当前局部变量名不能在同一可见作用域重复；独立分支可以复用同名局部变量。
- 前向局部引用、分支局部逃逸、未知局部赋值、返回后语句、缺少返回以及块内 `凡` 目前均以 `S-3068` 拒绝。
- 局部初始化或赋值中出现输入、数组写入或映射写入时以 `S-3068` 拒绝，因为这些纯函数块会被替换进调用点，重复引用局部值不能造成重复副作用。输入效果仍可出现在条件或返回表达式中，并须按既有效果规则逐层声明。
- 块体在编译期消解为表达式：局部绑定按顺序替换，提前返回降为惰性 `ifElse`，之后继续使用现有参数替换、递归检测、效果检查和有界 AST 展开。

## 理由

编译器自身需要先用块体函数组织解析和检查步骤。词法局部作用域、顺序局部绑定和返回分支足以验证调用边界，同时继续复用已经验证的类型检查器与原生后端。把块体消解为表达式保持当前 stage0 的有限实现边界，不引入尚未设计的机器调用栈。

## 边界

- 这是值语义与词法作用域子门，不是运行时 ABI；没有独立栈帧、通用保存/恢复寄存器、动态分配闭包或递归。
- 函数块暂不支持 `凡`、`跳出`、`继续`、数组局部变量、捕获外层可变绑定或任意语句级副作用。
- 局部值仍受单个展开图 64 层和 65536 AST 节点预算约束；超出返回 `S-3063`。
- 不改变系统符号白名单、Go 子集、逐行归因、源码/产物独立性及 P3b 删除 `bootstrap/` 的硬门。

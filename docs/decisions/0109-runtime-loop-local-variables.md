# D-0109 运行时循环体内局部变量

状态：已验收（P1b 子门；不代表阶段门通过）

## 决定

D-0108 的无效果整数块体运行时函数扩展循环体局部变量。`变量 名称=初值。` 可在循环体、`若`/`否` 分支或嵌套 `凡` 中声明；声明执行到该语句时求值初值并写入该局部的独立栈槽，循环下一次到达同一语句时重新执行初始化。

本子门采用以下有限规则：

- 局部初值和赋值当前只能产生整数或运行时整数；文本、容器和结果载荷局部值继续由 `S-3068` 拒绝。
- 函数体内的局部变量名必须全局唯一，且不得与参数或常量重名。这样可以避免同一槽名在分支、嵌套块或循环迭代间形成未定义的遮蔽。
- 块作用域独立：循环体或分支中声明的局部值只在当前语句列表后续可见，循环结束后不能逃逸到函数作用域。
- 所有局部名称在函数入口一次分配到运行时栈帧；变量声明数量的上限与其他函数状态合计 502 个 64 位槽。
- 顶层局部变量仍须位于首个 `凡` 之前。循环体中的 `返回`、隐藏 IO、非整数局部值以及静态真循环条件继续拒绝。

函数仍以寄存器传参、直接 `BL` 调用及原生 `ret` 返回。本决定不改变文本/容器参数、效果函数调用帧、通用结果载荷或跨函数错误恢复 ABI。

## 理由

编译器自身会在多层循环中反复使用临时计数器、索引和局部结果。若只允许循环前声明，所有临时状态会挤到函数顶层并失去词法块边界。运行时帧预留槽可以直接承载这些局部值；每次执行声明时重新写入初值则使循环体行为可预测，并避免依赖上一轮迭代的残留。

## 验收

- `examples/p1b-runtime-loop-local.serica` 对输入 `5` 输出 `15`，循环中每轮声明 `增量=当前+1` 并累加。
- 原生门新增 3 个产物，覆盖每轮初始化、`若`/`否` 分支局部值及嵌套循环局部值；三个产物真实执行并返回 `15`、`14`、`18`，均要求 `bl` 与 `ret`。
- 编译反例覆盖函数内局部重名、循环局部逃逸、循环内文本局部值和含隐藏输入的局部初值；实际诊断分别为 `S-3068`、`S-3022`、`S-3068`、`S-4106`。
- `make test-p1b-runtime` 通过 145 个 arm64 整数形态、其中 12 个运行时整数块循环函数产物、254 个编译诊断和 116 个运行时拒绝样例。
- `make seed-audit` 通过 8895/12000 行及 C-1 5894/8520（69.2%）。
- P1b 阶段门仍未通过；循环体返回、文本/容器局部状态、效果函数帧和通用错误恢复留待后续子门。

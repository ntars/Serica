# D-0132 行简原生整数与控制流发射

在绑定和能力检查完成后，`native-code` 将整数、布尔、语句块和被调用的标量函数降为 ARM64 指令。编译器从原语法树读取常量和声明，沿绑定引用解析变量、函数与循环控制目标。它为函数局部值读取已知的 ABI 槽位，为参数分配 x0–x7，并为返回和前向调用统一回填跳转。x29 链接标准帧记录，x28 指向局部槽，调用时保持栈 16 字节对齐。

生成代码支持短路且、故与 `ifElse`，若否、凡、跳出、继续、提前返回、直接及相互递归。整数加减、取负、乘除、余数和移位沿用种子的边界。算术和输入失败跳至退出例程，退出码为 1，stdout 为空。布尔根输出使用 `1` 和 `0`。

发射器为动态输出添加行简生成的十进制转换与短写循环。程序有实际 stdin 需求时才写入 `_read` 绑定和整数输入例程。整数读取按字节读取至 LF 或 EOF，保留负号、CRLF、63 字节内容和 int64 边界。种子只用于构建发射工具和写出原始字节。上下游以 ASCII 模式字节和九位十六进制指令词传递代码，额外的词值用于内部运行时链接。

构建包装先使用 D-0131 的静态路径。静态子集返回 `S-3080` 后，包装改用行简动态发射。原有签名、同路径重建、失败保留旧文件和平台检查继续执行。暂不发射动态文本、容器、结果载荷和超出 stdin/stdout 的 IO。P1b 阶段门仍在推进。

## 验收

```sh
env GO=/Users/ntars/.local/go1.27.4/bin/go make test-p1b-native-emit
```

macOS arm64 实测保留 9 个静态签名运行产物、8 个 stage0 参照和 8 个编译拒绝场景，新增 10 个动态签名 Mach-O 与对应 stage0 产物。动态矩阵覆盖 47 次输入和退出状态对照，其中 21 次运行时拒绝在 stdout 为空时退出 1。验证嵌套循环的跳出与继续、递归返回、跨模块常量和八寄存器传参、算术边界、多个输入和多页指令段。对照了段布局、导入、签名、槽位访问及真实 ARM64 分支、`bl` 和 `ret`。跨模块的动态产物同路径重建逐字节一致。

编译器闭包为 11 个文件、13 条依赖边和 168 条跨文件绑定。活动 Go 种子保持 10347/12000 行，C-1 为 6634/9896（67.0%）。

# D-0049：运行时文本拼接静态操作数

## 决策

扩展 D-0042/D-0047：`textConcat（左，右）` 的操作数可为已初始化的有界运行时文本变量，或不超过 63 字节的编译期字符串表达式。静态文本可以位于左侧或右侧，也可通过不可变字符串常量引用。拼接结果仍最多 63 字节；后端使用 Mach-O 常量区和固定 scratch 栈缓冲区，不分配堆内存。

执行时先检查合并字节长度，再写入输出目标。超限时在 stdout 前非零退出，不输出部分结果；变量别名写回继续有效。动态表达式嵌套、运行时动态增长和超出 63 字节的字符串仍不支持。

## 验收

`make test-p1b-runtime` 构建并执行 `examples/p1b-runtime-text-concat-literals.serica`，覆盖静态字符串表达式前缀、常量引用后缀、ASCII/中文/空输入、精确 63 字节、前后缀造成的两类超限，以及无部分输出；同时保留 ARM64 复制循环和 `_read`/`_write`/`_exit` 白名单检查。当前运行时门通过 62 个成功文本输入、51 个编译诊断和 43 个运行时拒绝样例。P1b 阶段门仍未通过。

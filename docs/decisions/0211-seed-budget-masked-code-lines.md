# D-0211 种子预算口径统一为掩码代码行

日期：2026-11-26
状态：已定案

## 背景

D-0210 之后，活动种子同时出现 `12779` 与 `12581` 两个看似都应代表预算使用量的数字。前者是 `wc -l` 物理行，后者是当时决策快照中的旧口径；两者相差不只空白和注释，还包括后续必要修正。手册 M0/S0.2 要求把差额解释清楚，S0.3 要求把 `make seed-audit` 的机器输出固定为唯一口径。

## 决策

现行种子预算使用“掩码代码行”：

- 只统计 `bootstrap/` 下 10 个活动 Go 源码文件；
- 排除 `bootstrap/archive/`；
- 不计空白行；
- 不计 `//` 与 `/* ... */` 注释；
- 不计字符串和字符字面量的内容；
- 与逐行归因仍使用物理行范围，二者不得混用。

机器上限保持 D-0210 的 12800 行不变。`make seed-audit` 必须同时打印口径、已用、上限和余量，并另报物理行供归因核对。

## 当前实测

2026-11-26 本机快照：

| 口径 | 数值 | 用途 |
|---|---:|---|
| 活动文件物理行 | 12779 | 逐行归因范围核对 |
| 活动文件掩码代码行 | 12558 | 现行预算口径 |
| 排除归档后的物理行 | 12779 | 归档不进入活动种子 |
| 若包含归档的物理行 | 12975 | 解释为什么不能直接使用全目录 `wc -l` |

归档目录 `bootstrap/archive/prototype-3.8/` 为 1 个文件、196 个物理行。旧快照中的 82 行差额主要来自物理行与掩码代码行的差异，以及后续 P1b 修正；历史 ADR 中的数字保留为当时证据，不再作为现行余量。

## 验收

```sh
env GO=/Users/ntars/.local/go1.27.4/bin/go make seed-audit
```

预期首两行明确输出“口径：掩码代码行”和 `12558/12800 行，余量 242`，并继续通过归因、Go 子集、依赖白名单与 C-1 检查。

本决策只统一预算口径，不表示 P1b、语言或产品完成。

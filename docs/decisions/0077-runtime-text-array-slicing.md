# D-0077：运行时文本数组元素切片

- 状态：已定案
- 日期：2026-11-21
- 领域：P1b 原生运行时

## 决策

允许 `substring（arrayGet（文本数组，索引），起点，终点）` 直接切片运行时文本数组元素。数组索引可为运行时整数，范围在执行时检查；切片起止按 Unicode 标量值计算，范围保持 `0 ≤ 起点 ≤ 终点 ≤ 63`。元素字节来自已验证的 UTF-8 输入或文本数组复制路径，切片不执行归一化。

读取数组索引、访问数组项和扫描码位均在根输出前完成。负/越界数组索引、索引输入格式错误及元素长度不足以覆盖终点时，原生程序以非零退出且不输出。该能力不增加数组变更、不改变 `_mmap`/`_munmap` 白名单，也不放宽一般动态文本表达式限制。

## 验收

- `examples/p1b-runtime-text-array-slice.serica` 使用运行时索引从 CJK 和补充平面字符串元素分别切出“行简”和“𠮷行”。
- `make test-p1b-runtime` 覆盖负/越界数组索引、非法整数输入和切片终点超过元素长度的无输出失败。
- 当前运行时门通过 134 个成功文本输入、95 个编译诊断和 92 个运行时拒绝样例；种子为 6500/6500 行，C-1 为 4239/6019（70.4%）。P1b 阶段门仍未通过。

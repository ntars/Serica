# D-0047：运行时文本拼接直接输出

## 决策

扩展 D-0042：`textConcat（左，右）` 除了初始化或更新有界文本变量，也可直接作为 `程序` 根的 `输出` 表达式。两个参数仍必须是已初始化的运行时文本变量，连接结果最多 63 字节。

直接输出路径使用固定 64 字节 scratch 和一个长度槽；先验证总长度，再生成完整 UTF-8 结果并调用 stdout。超过上限时在写出任何字节前以非零状态退出。此能力不引入堆分配，也不允许静态操作数、嵌套拼接或一般表达式。

## 验收

`make test-p1b-runtime` 实际执行直接输出拼接 Mach-O，验证 ASCII、中文、CRLF、空串、精确 63 字节、超限无部分输出，并核对 ARM64 长度检查和 Mach-O 系统符号。当前运行时门通过 58 个成功文本输入、51 个编译诊断及 41 个运行时拒绝样例。P1b 阶段门仍未通过。

# D-0059 Go 种子 AST 占比触发条件复核

状态：已定案（沿用 Go 临时自举桥；不放宽 P3b 删除门）

## 机器测量

`make seed-audit` 统计种子根目录 Go 文件中非空、非注释行，并按 `docs/build/seed-attribution.md` 的 `【AST】` 标签统计 AST 构造、遍历、语义分派和直接消费 AST 的控制台生成器代码。2026-11-21 的结果为 3344/5021 行（66.6%）；种子总计 5472 行，已超过 D-0009/C-1 的 3000 行检查点。因此 C-1 的 40% 条件已触发。

## 决定

不在当前阶段把临时种子改写为 OCaml。所有者明确授权把开发手册视为构想、在保持核心目标时灵活调整实现方案。此 Go 种子仅作为受限过渡桥，位于 `bootstrap/`、固定 Go 版本、执行白名单和逐行归因、限制 5500 行、保持 Apache-2.0 与系统依赖审计，并将在 P3b stage2/stage3 归一化一致后整体删除。现在移植到另一种临时编译器语言会增加一次完整重写，不能替代最终由 Serica 接管编译器、运行时、标准库和工具链的目标。

这是对手册 C-1 默认接替方向（OCaml）的明确偏离，不改变自举、独立性、许可、产物或种子删除验收。`make seed-audit` 持续输出该占比，并要求本复核记录存在；若目标改为长期维护种子，或 P3b 删除条件不能兑现，必须重新评估此选择。

- `./tools/check-independence source`、`make license` 仍为独立硬门；本决定不豁免这些检查。

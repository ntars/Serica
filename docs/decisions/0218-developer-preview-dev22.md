# D-0218 开发者预览 dev.22 发布包

本机完整验证门在加入文本返回借用上下文修复、41 例一致性套件、规范草案和保守格式化器后通过。本决策将 `VERSION` 从 `v0.1.0-dev.21` 提升到 `v0.1.0-dev.22`，重新生成 macOS arm64 源码与运行时分发包。包内含可直接运行的种子编译器、控制台/窗口示例、自编编译器源码、完整文档树、`SHA256SUMS`、`sbom.json` 与安装/卸载脚本，并在发布目录内执行运行验收和隔离安装/卸载验收。

发布包继续明确标记为开发者预览：P1b 阶段门、P2b 自举置换、Apple 公证、图形安装器、多机验证和 1.0 兼容承诺均未完成。发布构建不引入第三方依赖、C/LLVM 中间层或宿主绝对路径。

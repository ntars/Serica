# D-0039 固定长度运行时整数数组

状态：已落地子门；不构成 P1b 阶段门通过。

## 决定

在 P1b 原生输出子集中，可变整数变量可由 `array（整数，…）` 初始化为固定长度数组。数组元素与标量变量共用 ARM64 栈帧及现有 502 个整数槽预算。`arrayGet（数组，索引）` 读取元素，`arrayLength（数组）` 返回编译期已知长度；语句 `赋值 数组=arraySet（数组，索引，值）。` 原地更新该变量。

索引和值可以是运行时整数。静态越界在语义检查时报错；运行时索引先检查小于零与大于等于数组长度，越界时在 stdout 输出前以非零退出。写入的值仅接受整数。更新表达式必须引用与赋值目标相同的顶层数组变量。

## 范围

这项实现只覆盖固定长度、整数、栈分配数组。长度在编译期确定，元素在声明时一次性分配栈槽。它不实现堆分配、可变长度/增长、字符串数组更新、哈希表、迭代器、通用容器接口或结构化错误传播。

## 验收

- `make test-p1b-runtime` 实际执行 68 个整数 Mach-O 和 1 个 UTF-8 文本 Mach-O。
- `examples/p1b-runtime-integer-array.serica` 以输入 `5\n1\n42\n` 初始化数组、更新索引 1 并输出 `42\n`；测试还覆盖常量引用及内联数组字面量索引。
- 反汇编验收数组初始化、间接 `str`/`ldr`、索引移位寻址及上界条件跳转。
- 静态上界错误、非数组目标和非整数值分别命中预期诊断；运行时负索引和长度上界以非零退出且无输出。
- 34 个编译诊断、22 个运行时拒绝样例及现有 Mach-O/dyld/系统依赖/导入符号/签名和 502 槽边界回归通过。
- `make seed-audit` 保持 Go 子集、逐行归因及 5000 行预算；P1b 总门仍缺动态分配容器、字符串运行时、错误值传播、通用 IO 和行简编译器。

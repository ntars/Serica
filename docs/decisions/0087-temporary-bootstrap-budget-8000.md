# D-0087 临时自举桥行数预算扩至 8000

状态：已定案（所有者授权；自举、独立性和删除硬门不变）

> 活动预算其后由 D-0101 扩至 12000 行；本文保留当时的 8000 行决策与验收证据。

## 背景

整数键值哈希映射加入后，活动 Go 种子达到 6838 行，超过 D-0061 的 6500 行上限。所有者在当前任务中明确授权：“必要时可以扩大种子行数。”

## 决定

将活动 Go 种子的机器检查上限从 6500 行调整为 8000 行。该调整只增加临时桥的有限实现空间，并保留以下硬门：

- 种子只位于 `bootstrap/`，固定 Go 版本和允许的标准库子集。
- 每个非空实现行继续登记在 `docs/build/seed-attribution.md`。
- 继续执行源码依赖、许可证、系统符号、平台和产物独立性检查。
- stage0 不得成为产品运行时；P3b 仍须完成 stage1→stage2→stage3 四段归一化一致并整体删除 `bootstrap/`。
- 若 8000 行不足以完成自举，优先压缩或重构种子，并把再次扩额作为单独决策审查；不得把预算调整视为放宽 P1b 或 P3b 验收。

## 验收

- `tools/check_seed_subset.py` 的 `MAX_SEED_LINES` 为 8000。
- `make seed-audit`：6838/8000 行，Go 子集、逐行归因和依赖边界通过；C-1 AST 归因为 5202/6508 行（79.9%），条件复核继续触发并由 D-0009/D-0059 记录。
- README、零知识检查、模块档位、阶段清单和种子归因表同步引用 D-0087。
- 完整硬门实跑通过：`stage0`、`test-p0b-scope`、`test-p1b-static`、`test-p1b-modules`、`test-p1b-runtime`、`doctor`、`license` 和 `seed-audit`；运行时报告 106 个整数形态 ARM64 产物（其中 8 个映射）、139 个成功文本输入、173 个编译诊断和 103 个运行时拒绝样例。
- 许可、源码独立性、映射样例标点扫描、JSON 解析和 `git diff --check` 均实跑通过。P1b 阶段门仍未通过。

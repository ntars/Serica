# D-0058 运行时拼接切片结果

状态：已定案（P1b 子门；不代表阶段门通过）

`textConcat（左，右）` 的操作数新增运行时 `substring` 结果。为保持临时区和求值次序可证明，切片源限定为已初始化文本变量，索引继续按现有 0–63 Unicode 标量值规则检查；不在拼接操作数中接受以另一 `textConcat` 结果为源的嵌套切片。拼接仍是二元运算，其他运行时操作数仍为已初始化文本变量，静态操作数最多 63 字节。

切片结果先写入左右分离的临时缓冲区，再由拼接路径读取，因此切片源可与赋值目标别名。变量写回可结合最多 252 字节的切片结果并按 D-0056 扩展至 16 MiB−1 字节；映射分配、复制与旧目标释放顺序保持不变。根直接输出和 `textLength（textConcat（…））` 仍使用 63 字节拼接 scratch，上限在 stdout 前检查。未引入第三方运行时或分配器。

## 验收

- `make test-p1b-runtime` 编译并执行切片后拼接的变量别名写回；覆盖 63 个四字节码位切片后追加静态后缀（255 字节总结果）和多字节短输入。
- 编译诊断拒绝以拼接结果为源的嵌套切片操作数；既有拼接/切片最大值、UTF-8、索引、别名、无部分输出和系统符号白名单回归继续通过。
- 完整 `make test-p1b-runtime` 通过：73 个整数 Mach-O、105 个成功文本输入、56 个编译诊断和 71 个运行时拒绝样例；新增产物只导入登记的系统接口。`make seed-audit` 通过：10 个活动源码文件、5472/5500 行，白名单和逐行归因完整。P1b 阶段门仍未通过。

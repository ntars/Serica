# D-0021：P1b 有符号整数常量算术

> 当前实现状态：本决策定义编译期有符号 64 位算术；D-0027 增加固定表达式的原生 ARM64 执行，D-0029 增加整数变量栈槽，D-0030 增加静态可证的变量算术/位运算，D-0034 增加带运行时边界检查的整数运算。尚无结构化错误值、恢复或传播。总状态见 [全阶段清单](../roadmap/p0b-p6b.md)。

## 决策

整数常量采用有符号 64 位范围 `-9223372036854775808..9223372036854775807`。支持一元负号、分组及二元 `+`、`-`、`*`、`/`；乘除优先于加减，同级左结合。`+` 按推断类型执行字符串拼接或整数加法，其他算术只接受整数。除法向零截断。

加减乘除和一元取负均检查有符号溢出，返回 `S-3018`；除数为零返回 `S-3024`；非法类型组合返回 `S-3023`。`bitAnd`、`bitOr`、`bitXor` 对有符号整数的 64 位二进制补码位模式运算。`substring` 仍要求最终起止索引位于字符串码位范围内，负索引按越界诊断处理。

本决策的样例在编译期检查和求值，再将字符串结果写入 Mach-O。D-0027 新增的 `程序` 根绑定会对固定整数表达式生成原生算术指令；D-0029 增加受限整数变量栈槽，D-0030 使无输入/控制流且可静态证明安全的变量表达式生成原生算术指令。本决策的编译期常量语义不随之改变。

## 边界

不支持取余、移位、赋值或整数变量存储。当前仅在 `程序=【输出=...】` 中执行固定整数表达式，所有中间结果仍受有符号 64 位范围检查；最小值可写作 `-9223372036854775808`，但对该值再次取负会溢出。

## 验收

`examples/p1b-integer-arithmetic.serica` 用 `2+2*2`、`10-20/4`、分组、负的最小整数、`-7/2` 向零截断与负数位与计算 `[6,7)` 切片，产物包含“力，整数运算通过”。负例分别验证乘法溢出、除零、最小整数除以 `-1`、最小整数取负及类型错误。所有正负例通过 `punct-scan`；正例通过 Mach-O/dyld 校验。

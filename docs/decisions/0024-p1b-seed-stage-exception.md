# D-0024：P1b 阶段 Go 种子范围例外

> 历史记录。D-0025 已取代本例外；它不构成手册 §3.7/§4.6 的许可，也不作为当前阶段验收依据。

## 决策

用户在前述实现路线裁定请求后指示“继续进行自动推进”。为继续完成既定 P1b 目标，本任务允许在 `bootstrap/` 中实现 `docs/roadmap/p0b-p1b.md` 已列出的 P1b 语言能力，包括 D-0023 的模块导入。实现范围仅限这些语言能力、必要诊断和对应验收；不增加无关产品逻辑，不引入第三方包。继续执行 Go 精简子集、5000 行上限、逐行归因和 P3b 删除种子要求。

## 与开发手册的关系

这是本任务的阶段性执行例外，和外部《行简 Serica 开发手册》3.7/4.6 的“种子只修 bug”条款存在明确冲突；本记录不修改外部手册，也不把冲突表述为手册已经批准例外。若项目所有者之后要求严格执行种子冻结，应停止新增种子能力并重新裁定实现路线。P1b 总验收仍按手册第八节要求执行，完成这些编译期子集不代表阶段门通过。

## 验收

模块实现须由 `make stage0` 编译；`make test-modules` 验证传递导入、共享依赖去重及导入顺序反转样例写到相同路径后生成字节相同的 Mach-O；9 个 `S-4001` 至 `S-4005` 诊断夹具返回预期码；路径越界、符号链接、非 UTF-8 和大小写不匹配路径不得被接受。代码增加后更新种子归因表和行数证据。

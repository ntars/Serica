# D-0018：P1b 整数常量索引加法

> 当前实现状态：stage0 支持编译期整数表达式、固定整数原生执行和静态可证的整数变量运算（D-0030）；D-0034 又加入带溢出/除零/移位检查的运行时整数运算，但尚无结构化错误值或传播。总状态见 [全阶段清单](../roadmap/p0b-p6b.md)。

## 决策

`substring` 的起点与终点允许非负 64 位整数常量通过 ASCII `+` 左结合求和。结果不得超过 `9223372036854775807`；溢出返回 `S-3018` 语义诊断。索引仍须满足切片的码位范围约束。

## 边界

这是最初的 P1b 编译期整数常量子集；D-0021 后续扩展为有符号 64 位加减乘除和一元负号。整数仍仅在编译期求值；没有通用整数变量或运行时整数值。其他上下文的 `+` 仍由该上下文的类型语义判定。

## 验收

`examples/p1b-string-slice.serica` 用 `1+1` 与 `2+3` 计算切片索引；构建产物包含“语言表可运行”。`examples/diagnostics/p1b-index-overflow.serica` 检查时返回 `S-3018` 非零诊断。源码通过 `punct-scan`，成功产物通过 Mach-O/dyld 校验。

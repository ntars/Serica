# D-0038：运行时短路逻辑

**状态：** 已实施；P1b 运行时子门通过。  
**日期：** 2026-11-21  
**范围：** 比较条件组合、短路求值和布尔条件控制流。

## 决策

复用保留关键字 `且` 与 `故` 组成逻辑与、逻辑或。`且` 优先级高于 `故`，二者均左结合；条件节点只可用于 `ifElse`、`若` 和 `凡`，不能作为整数或字符串输出。组合条件不创建可存储的布尔变量。

静态条件在编译期按短路规则求值。动态条件由 ARM64 条件分支构成：`且` 左侧为假时跳过右侧，`故` 左侧为真时跳过右侧。被跳过的表达式不会读取输入，也不会触发运行时错误。

## 验收

- `make test-p1b-runtime` 实际执行 64 个整数 ARM64 Mach-O 和 1 个 UTF-8 文本 Mach-O。
- `examples/p1b-runtime-logical-conditions.serica` 验证 `且` 高于 `故`、动态组合分支及两种短路路径；只提供第一行输入仍能成功，证明 `且` 右侧读取已跳过。
- 两个静态逻辑正例与三种动态逻辑结果通过；ARM64 反汇编包含各比较分支。
- 31 个编译诊断、20 个运行时拒绝样例、Mach-O/dyld/系统依赖/导入白名单/签名和 502 槽上限通过。

## 后续边界

逻辑条件组合不等于布尔变量或通用逻辑类型；错误值与传播、动态字符串/容器、一般 IO 及编译器表达能力仍未完成，P1b 阶段门保持未通过。

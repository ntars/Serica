# D-0029：原生整数变量栈槽子门

## 决策

> 历史状态：本决策首次验收仅开放变量直接引用；D-0030 后续允许静态可证的整数变量运算。以下数量为 D-0029 原始验收记录，当前扩展证据见 D-0030。

扩展 `程序=【输出=...】` 根程序，支持顶层 `变量 名称=整数表达式。` 声明、`赋值 名称=整数表达式。` 更新，以及在初始化、赋值或最终输出中直接引用此前声明的整数变量。每个变量占一个原生 ARM64 栈槽；声明和赋值生成 `str`，读取生成 `ldr`。当前最多 502 个变量，以保持不超过 4080 字节的 16 字节对齐栈帧，并为整数转文本留出 64 字节缓冲区。

在 D-0029 原始实现中，表达式若包含变量引用但不只是直接引用，则拒绝为 `S-3039`。因此当时变量的加减乘除、位运算和一元运算尚未开放；D-0030/D-0031 后续分别扩展静态可证算术、位运算、余数和移位。变量仍仅为整数，字符串仍只在编译期确定。模块仍只接受导入和常量，变量语句只允许出现在入口文件的 `程序` 根绑定之前。

## 边界

- 产物继续由仓库内 Mach-O/ARM64 后端直接生成；不调用 C 编译器、LLVM、外部汇编器或链接器，也不包含 Go 运行时。
- 仅在当前 macOS arm64 平台验收；系统依赖仍限定为 `libSystem.B.dylib` 的 `_write` 与 `_exit`。
- 此子门属于 D-0026 临时 Go 自举桥；P1b 总门仍未通过，最终实现仍须由 Serica 接管，并在 P3b 删除整个 `bootstrap/`。
- 变量执行顺序、重复声明、未声明赋值、前向引用和变量复合表达式均由语义检查固定，避免生成未初始化读或未保护的运行时算术。

## 验收

- `make test-p1b-runtime` 实际运行 14 个整数 Mach-O 和 1 个 UTF-8 文本 Mach-O；`examples/p1b-runtime-variable.serica` 覆盖常量初始化、变量重赋值和最终读取，另验证导入常量初始化变量及 502 槽最大偏移。
- 变量产物经 `otool -tV` 检查含 `str x0, [x19]` 与 `ldr x0, [x19]`，并分别通过 Mach-O 架构、dyld、依赖、导入符号和签名检查。
- 原始 9 个负例覆盖溢出、除零、错型、未知赋值目标、重复变量、变量前向引用、当时不支持的变量算术、变量语句用于窗口根和超限变量数；均须在生成前报出对应诊断。
- 通过只表示整数栈槽与受限变量语义成立，不代表动态字符串、一般表达式溢出陷阱、动态容器、通用 IO、错误传播或完整 P1b。

# D-0086 有界整数键值哈希映射

状态：已定案（P1b 子门；不代表阶段门通过）

## 决定

控制台程序支持一种可从空值创建、更新和读取的整数键值哈希映射：

- `映射（）` 创建空映射；变量保存桶指针、条目数和桶容量三个原生栈槽。
- `映射置（映射，键，值）` 写入一个有符号 64 位整数键和值，并要求 `map.write` 能力。
- `映射取（映射，键，默认值）` 读取整数或将缺失键映射为调用方提供的整数默认值。
- `映射有（映射，键）` 返回布尔成员状态。
- `映射长（映射）` 返回当前唯一键数。

映射使用匿名映射保存桶指针和独立链式条目。键按 64 位乘法哈希分配桶；覆盖已有键只更新值，不增加长度。负载达到 3/4 时桶容量翻倍，遍历旧链并把节点重新链入新桶，再解除旧桶映射。初始容量为 64，容量上限为 2^24 桶；映射变量占三个栈槽，因此当前最多允许 167 个映射变量。

## 理由

该子门覆盖哈希分配、碰撞、链式查找、覆盖更新、动态重排和容量边界，同时复用已登记的 `_mmap`/`_munmap`，不引入第三方容器或 Go 运行时。整数键值范围给出可机器测试的明确 ABI，先验证容器核心语义，避免同时引入泛型、文本键、结构值或序列化。

## 边界

- 当前只支持有符号 64 位整数键和值；文本、布尔、浮点、结构和任意值类型留待后续。
- `映射置` 只能写回目标映射自身，并要求根能力或函数调用链逐层声明 `map.write`。
- 映射不能直接作为根输出，也不能隐式转换为整数、布尔、文本、数组或结果。
- 条目节点在重排时复用，旧桶映射被解除；当前不提供删除单项或收缩容量。
- 哈希按 64 位二进制补码乘法执行，碰撞通过桶内链处理。

# D-0057 动态运行时文本切片

状态：已定案（P1b 子门；不代表阶段门通过）

将 `substring（文本，起点，终点）` 写入动态文本变量时，结果不再受 63 字节 scratch 限制。源仍为运行时文本变量或单层 `textConcat` 结果，索引仍是零起始 Unicode 标量值，范围限定在 `0..63`；因此最多返回 63 个码位、252 个 UTF-8 字节。目标先取得独立映射，复制完整切片并写入 LF，再解除目标变量旧映射并提交新指针和容量。源映射在复制完成前保持有效，允许目标与源别名。

直接从根程序输出切片仍检查实际 UTF-8 字节数不超过 63，并在写入 stdout 前拒绝超限结果。`textLength（substring（…））` 使用分离的临时缓冲区，长切片计长不会覆盖整数输出区。映射、解除映射失败和索引/源范围错误均在 stdout 前非零退出；只使用已登记的系统 `_mmap`/`_munmap`。

## 验收

- `make test-p1b-runtime` 执行长切片写回：从 100 个补充平面码位中切出 63 个并写回同一变量，输出 63 个完整码位；另执行 63 个码位切片的 `textLength`，结果为 `63`。
- 同一门验证 63 个四字节码位（252 字节）的根输出切片在 stdout 前非零失败，以及已有 63 字节根输出边界、切片索引/源范围错误、UTF-8、别名和拼接切片回归。当前完整门执行 73 个整数 Mach-O、103 个成功文本输入、55 个编译诊断和 71 个运行时拒绝样例。
- `make seed-audit` 检查活动种子 5434/5500 行、Go 白名单子集与逐行归因；切片结果存入变量只引入登记的系统映射调用。P1b 阶段门仍未通过。

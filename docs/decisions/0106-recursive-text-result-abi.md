# D-0106 递归编译期文本结果调用 ABI

状态：已验收（P1b 子门；不代表阶段门通过）

## 决定

无效果声明且构成递归环的函数可以在 D-0103/D-0104 的真实 ARM64 栈帧上返回编译期文本结果。函数参数仍只接受整数，并通过 `x0` 至 `x7` 传递；返回值使用以下固定寄存器组：

- `x0` 是结果标签：`0` 表示成功，`1` 表示失败。
- 整数结果成功时 `x1` 保存载荷；编译期文本结果成功时 `x1` 为 `0`。
- 编译期文本结果成功时 `x2` 指向 Mach-O 常量区中的静态 UTF-8 字节，`x3` 保存字节长度。
- 失败时 `x1` 保存 `1..255` 错误码，`x2` 和 `x3` 均清零。

调用结果保存到四槽结果变量。把结果值复制到普通文本变量时，编译器为目标分配独立缓冲区并深复制有效内容，因此后续结果重赋值不会改变目标文本。静态文本没有运行时所有权；目标文本缓冲区仍遵循既有映射、UTF-8 和长度边界。

当前只开放编译期文本成功载荷。运行时文本表达式载荷、文本或容器参数、容器结果载荷、效果函数返回和通用错误恢复仍未进入该 ABI；递归函数返回运行时文本载荷继续由 `S-3023` 拒绝。

## 理由

整数结果 ABI 只使用 `x0/x1`，文本结果还需要指针和长度。复用 `x2/x3` 可在不把静态文本复制进调用帧的情况下验证调用、失败传播、四槽保存和深复制边界，同时保持普通递归整数函数的行为不变。

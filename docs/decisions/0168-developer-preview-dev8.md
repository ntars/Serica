# D-0168 开发者预览 v0.1.0-dev.8 发布复验

## 决策

将开发者预览版本从 `v0.1.0-dev.7` 递增到 `v0.1.0-dev.8`，同步修正开发手册与路线图的当前基线计数，重新生成发布目录、压缩包、逐文件 SHA-256、SBOM 和归档 SHA-256，并复跑解压后自动验收与隔离 prefix 安装/卸载。包格式和平台边界沿用 D-0141/D-0142。

## 验证

全量源码门、运行时门、模块效果/类型门、行简原生发射、doctor、许可、种子审计和独立性检查通过。运行时门为 204 个 arm64 整数形态产物、43 个运行时文本结果产物、27 个函数结果边界产物、335 个编译诊断和 123 个运行时拒绝样例；活动种子 11997/12000 行、C-1 4923/11839（41.6%）。`make release` 生成 `serica-v0.1.0-dev.8-macos-arm64` 目录、tar.gz 与 `SHA256SUMS.archives`；`tools/test_release.py` 和解压后 `make verify` 通过。P1b 阶段门仍未通过。

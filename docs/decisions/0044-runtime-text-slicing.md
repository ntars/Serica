# D-0044：有界运行时 UTF-8 文本切片

## 决策

`substring（文本变量，起点，终点）` 可切片由 `readText（）` 初始化的有界运行时文本变量。索引仍按 Unicode 码位计数，起点包含、终点不包含；两个索引须为编译期整数并满足 `0 ≤ 起点 ≤ 终点 ≤ 63`。动态输入不足以覆盖终点时，程序在输出前以非零状态退出。

切片结果可作为 `程序` 的输出，也可用于初始化或更新有界文本变量。后端按已验证的 UTF-8 首字节宽度映射码位到字节偏移，通过 64 字节栈 scratch 缓冲区生成规范化 LF 结尾；写回源变量也安全。结果不做 Unicode 归一化。

## 边界

本决策最初只允许编译期整数索引；运行时整数索引由后续 D-0045 扩展。仍不支持静态与动态文本混合操作数、用户感知字符（grapheme cluster）、排序比较（后由 D-0046 扩展）、堆分配、动态增长、容器或一般 IO。对短于终点的动态输入采用运行时失败，避免越界读取或部分输出。

## 验收

`make test-p1b-runtime` 实际构建并执行 4 个切片 Mach-O，覆盖 ASCII、中文、四字节 UTF-8 码位、最大 63 字节输入、上限索引 63、空切片、源变量别名写回及运行时输入过短拒绝；负索引、反向区间、超过上限和运行时索引分别由 `S-3013` 编译诊断拒绝。该子门不代表运行时索引或完整 P1b。

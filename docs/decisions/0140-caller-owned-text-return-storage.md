# D-0140 调用方顶层文本接管已拥有文本返回

无效果块函数的文本返回值可以由顶层变量声明或赋值语句接管。函数继续按 D-0115 的 ABI 在 `x0/x1/x2/x3` 返回成功标签、数据指针、UTF-8 字节数和映射容量。调用方先从返回描述符保存指针、长度和容量，再释放目标变量原有的映射，最后写入新描述符；这样即使 `_munmap` 破坏调用方保存寄存器，也不会丢失返回值。根输出路径仍复用原有转交例程，不对同一映射重复解除。

最小语义只覆盖整条右值就是一个文本返回调用的顶层 `变量`/`赋值`。嵌套表达式、条件、函数体、数组元素、容器逃逸和通用结果载荷仍由 `S-3023` 拒绝。失败路径保持非零退出与空 stdout。

env GO=/Users/ntars/.local/go1.27.4/bin/go make -j1 test-p1b-runtime

# D-0151 效果函数内结果局部的语句 ABI

带 `stdin` 效果的语句体函数可以在局部构造整数成功/失败结果并返回到调用方。成功载荷仍由相邻标签/值槽保存；失败路径不产生 stdout，并以原错误码退出。

## 根因

效果函数此前只有在包含 `凡` 循环时才保留语句形态。其余函数进入纯函数表达式 lowering，而该路径会展开局部变量初值，无法保留运行时结果的标签和载荷双槽。于是 `变量 结果=ifElse（开关==1，成功（readInteger（）），失败（8））` 在合法效果边界内仍被 `S-3068` 拒绝。

## 修复

- 新增效果函数结果局部识别：局部初值直接构造 `成功`/`失败`，或 `ifElse` 两个分支都构造结果时，函数继续使用真实运行时语句函数帧。
- 不改变结果局部双槽 ABI，也不放宽文本/容器结果载荷；只避免把必须跨效果执行保存的结果对错误折叠成普通表达式。
- 新增 2 个 macOS arm64 正例：开关 `1` 时读取并输出载荷 `42`；开关 `0` 时无 stdout 且以 `8` 退出。

## 验收

定向静态、模块、模块 ABI、绑定和行简原生发射门通过。`make test-p1b-runtime` 通过 183 个 arm64 整数形态产物、13 个函数结果边界产物、309 个编译诊断和 118 个运行时拒绝样例。`make seed-audit` 为活动种子 11938/12000 行、C-1 4879/11371（42.9%），归因完整。

## 边界

本决策只覆盖效果语句体函数的整数结果局部。效果函数中的文本结果局部、任意结果参数转发、效果调用作为函数实参、容器结果载荷与完整跨函数错误恢复仍未实现，P1b 阶段门仍未通过。

# D-0036：运行时整数大小比较

**状态：** 已实施；P1b 子门通过。  
**日期：** 2026-11-20  
**范围：** 整数条件表达式和 `ifElse` 分支选择。

## 决策

整数比较支持 `==`、`<`、`<=`、`>`、`>=`，并通过 `equals`/`notEquals` 函数提供相等和不等比较。比较结果是布尔条件，只能用于 `ifElse` 条件；不能直接输出、赋给整数变量或参加算术。静态整数比较在编译期求值，包含运行时整数的比较在 ARM64 产物中执行。

词法符号表保持不变。当前冻结集合不包含 `!`，因此不增加 `!=` 运算符；不等语义使用 `notEquals（左值，右值）`。

运行时条件沿用 D-0035 的分支布局，仅执行被选中的整数分支。字符串的 `equals`/`ifElse` 仍仅接受编译期可确定的值。

## 验收

- `make test-p1b-runtime` 实际执行 56 个整数 ARM64 Mach-O 和 1 个 UTF-8 文本 Mach-O。
- 编译期与运行时样例覆盖 `==`、`<`、`<=`、`>`、`>=`、`equals` 和 `notEquals`；运行时真/假结果、边界值、变量栈槽、条件分支和未选分支惰性均经实际执行。
- `examples/p1b-runtime-integer-comparison.serica` 验证 `readInteger（）>=10`，输入 `10` 得 `1`、输入 `9` 得 `0`。
- 25 个编译诊断及 19 个运行时拒绝样例通过；产物检查覆盖 ARM64 条件跳转、输入/输出符号白名单、dyld、系统依赖、签名和变量槽上限。

## 后续边界

本决策不增加通用条件语句、循环、布尔变量或比较结果传播，也不改变字符串运行时与错误处理状态。P1b 阶段门仍未通过。

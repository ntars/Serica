# D-0042 有界运行时文本拼接

状态：有界运行时子门通过；不构成 P1b 阶段门通过。

## 决定

新增 `textConcat（左，右）`，接受两个已初始化的运行时文本变量；初始只允许用于运行时文本变量的初始化或赋值；D-0047 后扩展为可直接根输出。拼接按 UTF-8 字节连接，结果最多 63 字节，使用既有 64 字节临时栈缓冲区，不分配堆内存。输入由 `readText（）` 校验为合法 UTF-8，因此字节边界拼接保持合法 UTF-8。

代码先计算两侧长度之和并检查上限，再将结果写入目标变量。目标可与任一来源变量相同；scratch 区避免复制时覆盖输入。超出 63 字节时以非零状态退出，输出字段尚未执行，因此 stdout 无部分文本。成功结果在末尾写入规范化 LF，长度槽记录文本字节数。

本决策初始子门不支持常量或字面量操作数、嵌套拼接表达式、切片、比较、动态增长、堆分配、容器、文件/进程 IO 或结构化错误传播。

## 验收

- `make test-p1b-runtime` 构建并执行两个拼接 ARM64 Mach-O，测试 ASCII、中文、CRLF、空文本、63 字节精确边界以及将结果写回来源变量。
- 拼接长度 64 字节及更大时，程序在 stdout 前以非零退出；`check` 阶段拒绝错误参数个数和非文本变量。
- 当前运行时门执行 68 个整数、1 个静态文本、1 个直接文本输入、2 个文本变量和 2 个拼接产物；20 个成功文本输入、43 个编译诊断和 34 个运行时拒绝样例通过。
- `make seed-audit` 保持 Go 子集、逐行归因和 5000 行预算；P1b 阶段门仍未通过。

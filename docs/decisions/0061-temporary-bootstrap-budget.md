# D-0061 临时自举桥行数预算调整

状态：已定案（原临时 Go 种子上限 6500 行；预算已由 D-0087 调整，其余自举和独立性硬门继续有效）

## 背景

P1b 运行时仍缺文本容器、通用 IO、结构化错误传播和足以实现行简编译器的表达力。活动 Go 桥达到 D-0053 原定的 5500 行预算。所有者已明确授权把开发手册当作项目构想并灵活调整实现方案，核心目标仍是由 Serica 接管编译器、运行时、标准库与工具链。

## 决定

将临时 Go 自举桥机器检查上限从 5500 行调整为 6500 行，为 P1b/P2b 过渡实现提供有限余量。此调整仅覆盖行数预算；活动种子仍只能位于 `bootstrap/`，继续执行固定 Go 版本、标准库子集、逐行归因、Apache-2.0、依赖与源码/产物独立性约束。stage0 不得成为产品运行时。P3b 仍须先证明 stage1→stage2→stage3 的四段归一化一致，再删除整个 `bootstrap/`。

若预计超过 6500 行，先缩小实现、重构临时桥或启动 Serica 编译器自举实现，不继续抬高预算。该上限不改变 P1b 阶段门或任何许可证、安全、平台、自举验收条件。

## 后续预算调整

所有者随后在当前任务中授权“必要时可以扩大种子行数”。D-0087 因此把活动种子的机器检查上限从 6500 行调整为 8000 行；本节所称“超过 6500 行继续抬高预算”的禁令由 D-0087 替代。D-0087 只有在 8000 行不足时要求优先压缩或重构种子，并把再次扩额作为单独决策审查。Go 子集、逐行归因、许可、源码/产物独立性、平台符号和 P3b 整体删除自举门均不因预算改变而放宽。

- [x] `docs/build/seed-attribution.md`、零知识检查表、阶段路线图与 README 同步列出当前 5500 行及 6500 行临时上限。

- [ ] P3b 自举不动点和删除 Go 种子尚未完成；P1b 阶段门仍未通过。

# D-0143 文本返回调用的借用操作数

无效果块函数的已拥有文本返回值现在可以在不经过顶层变量的情况下，直接作为只读文本操作数传给受支持的纯文本消费。当前范围是 `textLength`、`equals`、`notEquals` 与整数 `ifElse` 的条件链：`textLength（欢迎（输入））` 从 `x1/x2` 取得指针和有效字节数并按 Unicode 标量计长；`equals（欢迎（输入），『行简』）` 在映射释放前完成字节比较，再由 `ifElse` 二选一输出整数。调用方保留返回映射的生命周期语义，不把描述符写入普通文本变量槽。

根因修复：返回函数在参数求值后会重新调整栈帧，若在调用前没有预留描述符保存槽、或在其他栈调整后才保存 `x1/x2`，调用方保存寄存器会被覆盖并产生错误指针。现在固定先预留描述符保存槽，在调用后立即保存 tag、数据指针与长度，再校验错误码；借用完成后只在成功且持有映射时解除映射。比较路径把相等结果写入保存槽，在 `_munmap` 之后仍按该结果选择分支；`ifElse` 的静态折叠清单显式排除文本返回条件，避免运行时条件被常量折叠掉。借用消费者白名单仅放行 `textLength`、`equals`、`notEquals`，函数体、独立 `若` 条件、容器与结果载荷仍拒绝；`textConcat（欢迎（输入），...）` 反例保持 S-3044。

## 验收

```sh
make test-p1b-runtime
make seed-audit
```

# D-0163：开发者预览 v0.1.0-dev.5 发布复验

- 状态：已定
- 日期：2026-11-24
- 关联：D-0141、D-0142、D-0162

## 决策

将开发者预览从 `v0.1.0-dev.4` 递增到 `v0.1.0-dev.5`，避免把 D-0162 的文件删除、重命名与自编前端修正装入旧版本标识。包格式、源码运行时布局、本地 prefix 安装/卸载和验收流程沿用 D-0141/D-0142。

## 验收

- 全量源码门、运行时门、模块效果/类型门、行简原生发射、doctor、许可、独立性检查与种子审计通过。
- `make release` 生成 `serica-v0.1.0-dev.5-macos-arm64` 目录、归档、逐文件 SHA-256、SBOM 和归档 SHA-256。
- `tools/test_release.py` 验证文件集合、摘要、arm64 Mach-O、ad-hoc 签名、示例构建运行和隔离安装/卸载。
- 独立解压后 `make verify` 通过；归档 SHA-256 以 `dist/SHA256SUMS.archives` 为准。

该版本仍是 pre-alpha 开发者预览。P1b 阶段门、P2b–P6b、多机验证、系统安装器、Apple 公证与正式法务复核均未完成。

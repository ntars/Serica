# D-0010：AI 驱动治理与证据等级

## 决策

实现要求必须转成命令输出、字符串比对或限定用途截图。已定决策登记在 `DECISIONS.json`；每轮核对现有编号，新增决定先落盘。证据优先级为机器可验事实、限定用途截图、独立交叉审计、单模型自查。

## 取舍

接受截图不能复现、交叉审计仍有系统偏差、自查可信度最低等限制；不以叙述性结论代替客观证据。双 AI 审计只用于适合的阶段，不把未执行的审计写成已通过。

## 验证

每项零知识检查记录命令和期望输出于 `docs/build/zero-knowledge-checks.md`；中文渲染证据须附生成命令和输入文件。依据：手册第十节。

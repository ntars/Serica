# D-0037：整数语句控制流

**状态：** 已实施；P1b 运行时子门通过。  
**日期：** 2026-11-21  
**范围：** 整数比较条件、嵌套 `若`/`否` 语句、`凡` 条件循环。

## 决策

复用词法器中已保留的关键字与冻结符号：`若（条件）【语句】否【语句】。` 表达条件语句，`否` 分支可省略；`凡（条件）【语句】。` 在条件为真时重复执行。条件使用 D-0036 的整数比较和相等函数。

变量必须在控制块外声明，控制块内只允许赋值和嵌套控制语句。循环或动态分支中写入的变量在语义流分析后按运行时整数处理；所有实际加载、存储与条件跳转仍在生成的 ARM64 Mach-O 中执行。静态条件可在编译期选择分支，动态条件生成 `cmp`、条件跳转与回填后的分支目标。循环算术错误沿用 D-0034 的失败出口。

本决策当时不增加布尔变量、逻辑组合、`break`/`continue`、函数作用域或结构化错误传播；循环跳出与继续后由 D-0068 扩展。编译期恒真循环会生成无条件回跳。

## 验收

- `make test-p1b-runtime` 实际执行 59 个整数 ARM64 Mach-O 和 1 个 UTF-8 文本 Mach-O。
- `examples/p1b-runtime-integer-if.serica` 的动态真/假路径分别验证 `10 → 11` 和 `9 → 8`。
- `examples/p1b-runtime-integer-control-flow.serica` 在 `凡` 循环中嵌套动态 `若/否`，实际输出 `8`；反汇编检查变量栈槽、条件跳转与回跳。
- 29 个编译诊断覆盖非布尔条件、控制块内未知赋值和禁止的局部变量声明；20 个运行时拒绝样例包含控制块内整数溢出，确认失败不产生部分输出。
- 原生 Mach-O、dyld、系统依赖、符号白名单、签名和 502 个变量槽边界检查继续通过。

## 后续边界

此子门不构成 P1b 阶段出口。动态字符串/容器、通用 IO、结构化错误值/传播和行简编译器表达能力仍缺失。

# D-0138 行简字节写入与动态文本比较

`writeByteArray` 使用本帧可变整数数组，接受静态路径或 `argumentText`。它在打开目的文件前将全部元素检查为 0–255 并打包。成功返回实际写入字节数。短写按已写长度继续，创建、写入和关闭失败分别退出 21、22 和 23。失败路径关闭仍持有的描述符并解除打包映射。非法数组元素在打开目的文件前退出，已有文件的字节得以保留。

动态 `equals`、`notEquals`、`<`、`<=`、`>`、`>=` 共用逐字节比较例程。它从两个只读描述符读取有效范围，比较首个不相等的无符号 UTF-8 字节，或在前缀一致时比较长度。编译期常量、argv 借用、局部拥有型文本和借用形参采用同一字节语义，无 Unicode 归一化。

文件大小限额实验证实 stage0 原先在一次短写后跳过了循环条件更新，报告了未写入的字节。本轮修正种子读写循环的两个回跳位移。Go 种子保持 10347/12000 行，C-1 为 6634/9896（67.0%）。

## 验收

```sh
env GO=/Users/ntars/.local/go1.27.4/bin/go make -j1 test-p1b-native-emit
./tools/check-independence source
```

macOS arm64 实测 7 个签名产物、23 次 stage0 对照、5 个源码拒绝和 4 个载荷拒绝。文件大小限额为 128 字节时，两套产物均只写入前 128 字节并退出 22。测试对独立签名副本注入无效关闭描述符，取得退出 23。命名管道验证多次短读后 16 MiB−1 字节成功及 16 MiB 拒绝。原生程序用普通文件和项目限界模块读取实际发射载荷，再转写该文件，行简发射器消费转写后的文件，签名产物运行输出 `9`。比较矩阵覆盖补充平面字符、内嵌 NUL、不同归一化字节形式、前缀和 140,000 字节公共前缀。

本轮使用原始源码复验两项构建。分析器在 `变量 图正文=array（『』）` 处报告 S-3080，Mach-O 发射器在 `变量 系统名称=array（…）` 处报告同一诊断。两个构建接续动态文本数组验收。编译器闭包为 11 个文件、13 条依赖边、262 个跨文件绑定。[开发手册](../Serica开发手册.md)

全套回归首次运行时，分析器测试产物的 stage0 构建达到原有的 10 秒超时。独立复测检查为 9.86 秒、构建为 9.94 秒，均成功。测试辅助函数将仓库编译器源码的构建等待期限设为 30 秒，普通测试输入与运行产物继续使用原有超时。PART-0501 前 6 项及从中断项复跑的 12 项均通过，种子审计、许可、环境自检和源码独立性检查均通过。

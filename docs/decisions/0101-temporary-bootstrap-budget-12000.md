# D-0101 临时自举桥行数预算扩至 12000

状态：已定案（所有者授权；自举、独立性和删除硬门不变）

## 背景

D-0087 把活动 Go 种子上限设为 8000 行。D-0100 完成后，`make seed-audit` 实测 7967 行，仅余 33 行。P1b 仍需真实运行时函数 ABI、独立调用帧、块内循环、通用结果载荷、跨函数恢复、通用容器与更完整的文件和进程能力；这些能力无法在 33 行内可靠实现和验证。所有者在当前任务中已明确授权：“必要时可以扩大种子行数。”

## 决定

将活动 Go 种子的机器检查上限从 8000 行调整为 12000 行。该调整只为临时自举桥提供有限的 P1b/P2b 实现空间，不改变以下硬门：

- 种子只位于 `bootstrap/`，固定 Go 版本，并继续执行语言子集、标准库和依赖白名单检查。
- 每个非空实现行继续登记在 `docs/build/seed-attribution.md`，每项功能须有当前可复跑的正反例。
- 继续执行源码依赖、许可证、系统符号、平台和产物独立性检查。
- stage0 不得成为产品运行时；P3b 仍须完成 stage1→stage2→stage3 四段归一化一致并整体删除 `bootstrap/`。
- C-1 AST 占比条件继续触发并接受 D-0009/D-0059 复核；若种子转向长期维护或 P3b 删除条件无法兑现，必须重新评估语言选型。
- 12000 行仍不足时优先压缩或重构；再次扩额须另立决策，不得自动抬高。

## 验收

- `tools/check_seed_subset.py` 的 `MAX_SEED_LINES` 为 12000。
- `make seed-audit` 实测 7967/12000 行，Go 子集、逐行归因和依赖边界通过；C-1 为 5879/7617（77.2%）。
- README、零知识检查、模块档位、阶段清单和种子归因继续引用活动预算与 D-0101。
- 完整硬门实跑通过后，P1b 阶段门仍未因预算调整自动通过。

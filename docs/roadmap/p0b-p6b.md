# P0b–P6b 全项目阶段清单

本清单按《行简 Serica 开发手册》单一定稿执行；手册优先于本仓库历史说明。每个阶段只在硬验收命令、构建产物或实际交互证据可复核时标记通过。未实现的目标命令只作为待建接口，不代表当前可运行。

## 总状态

| 阶段 | 状态 | 判定依据 |
|---|---|---|
| P0b | **硬验收通过（macOS arm64，本机）** | 原生 Mach-O、依赖/符号/签名检查及可编辑中文窗口实测；见下文命令和 2026-11-20 记录 |
| P1b | **未通过；实现路线冲突待解决** | 活动 stage0 目前只实现 P0b 窗口记录字面量；字符串运行时、动态容器、IO、错误传播与模块实现均缺失。种子冻结后，stage0 无法编译行简编译器 |
| P2b | 未开始 | 依赖 P1b 通过；没有行简编译器源、stage1 或等价性证据 |
| P3b | 未开始 | 依赖 P2b；没有 stage2/stage3 四段归一化比对，也未删除 `bootstrap/` |
| P4b | 未开始 | 依赖 P3b；格式化器、包管理器、LSP 均未以行简实现 |
| P5b | 未开始 | 依赖自举主线；仍有登记的系统图形/文本过渡实现，A 档未达标 |
| P6b | 未开始；排在 P0b–P5b 之后 | 可视化编辑器未实现；不属于 1.0 门槛，不得拖延主线 |

**当前阻塞事实：** 手册 §3.7 禁止种子增加功能，§4.6 限定种子只负责编译行简编译器并要求 P3b 删除；第八节 P1b 又要求语言先具备写编译器所需的字符串、位运算、动态容器、文件/进程 IO、错误处理和模块系统。当前 stage0 只能编译受限窗口记录值，无法编译行简编译器。曾有的常量、数组、模块 Go 扩展已撤出活动种子；这些扩展从未解决运行时/IO 缺口，也不能作为冻结条款的豁免。当前没有不扩展 Go 种子的可行 P1b→P2b 路径或其验收证据，因此 P1b 及后续阶段保持未通过/未开始。

## 执行约束

- Go 种子只允许修 bug；保持 `bootstrap/`、≤5000 行、Go 白名单子集、逐行归因、Apache-2.0 和 P3b 删除条件。`make seed-audit` 机器核验子集、依赖、行数与归因。不得用任务例外覆盖手册。
- P1b 决策、规范和示例是未来行简实现的设计/测试素材；D-0024 与旧 Go 子集结果只作历史记录。当前活动 Go 种子已收回到 P0b 语法，不再接受 P1b 能力扩展。
- 所有第三方依赖须在 `docs/build/dependency-registry.md` 登记；仓库不保存副本。源码级、链接级、符号级、构建级和环境级独立性按手册附录 K 验收。
- 许可分层不可混用；`bootstrap/` 为 Apache-2.0，文档和工具按 `REUSE.toml` 映射。任何编译产物、生成文件和外部实现均须能追溯来源。
- 平台只有完成中文字形、中文输入法及候选框、字体回退、可复现 CI 产物和渲染黄金测试后才能标为“支持”；仅可编译时标为“构建目标”。
- 每轮结束更新本清单、`DECISIONS.json`、种子行数/归因和零知识检查，并自查手册附录 C。未运行的命令不标通过。

## P0b：种子编译器与最小运行时

**目标：** `serica build` 生成可执行程序，打开原生窗口，正确显示中文并可点击后编辑。

| 硬门 | 证据/命令 | 状态 |
|---|---|---|
| 受限源程序经共享解析/语义路径构建 | `make stage0`；`build/stage0/serica check examples/p0b-window.serica`；`build/stage0/serica build examples/p0b-window.serica -o build/p0b-window` | 通过 |
| P0b 正例、字段诊断和 P1b 拒绝边界 | `make test-p0b-scope` | 通过：正例及缺少 `文本` 字段的 `S-3006`；5 个代表性 P1b 形式被拒绝 |
| 原生产物、链接、符号、签名符合 macOS 当前白名单 | `file build/p0b-window`、`dyld_info -validate_only build/p0b-window`、`otool -L build/p0b-window`、`nm -u build/p0b-window`、`codesign --verify --strict build/p0b-window` | 通过（本机 arm64） |
| 中文窗口可交互编辑 | 运行 `build/p0b-window`，实际查看窗口并用键盘输入/删除；证据记录于 2026-11-20 本任务交互记录 | 通过（本机；不等于所有输入法/OS 版本均通过） |
| 环境、源码独立性和许可 | `make doctor`、`./tools/check-independence source`、`make license` | 通过（本机） |
| 同路径构建可复现 | 复制第一次产物到仓库外，再同路径重建并 `cmp`；SHA-256 记录见 `docs/roadmap/p0b-p1b.md` | 通过（本机，2026-11-20） |

**范围说明：** 此通过只覆盖手册 P0b 所述本机 macOS arm64 硬门，不扩展为 macOS 全版本或其他平台支持声明。跨平台支持仍由 P5b/平台矩阵验收。

## P1b：达到可写编译器的语言表达力

**目标：** 字符串、位运算、动态容器、文件与进程 IO、错误处理和模块系统足以表达行简编译器。编译期常量演算不能替代运行时语义。

| 子门 | 需要的证据 | 当前状态 |
|---|---|---|
| 语言运行时 | 字符串表示/操作、整数与位运算、动态数组、哈希表；正例和边界/错型诊断 | 缺失或只有编译期子集 |
| IO 与错误 | 文件/进程 IO、失败值和传播语义；成功/失败路径均有复跑示例 | 缺失 |
| 模块 | 编译器可用的模块闭包、接口/名称解析和稳定构建；诊断与循环/冲突反例 | 只有未来语言规范和素材；活动 stage0 不支持模块 |
| 源码卫生 | NFC、全角标点、禁用字符及错误位置检查 | 部分由 `build/punct-scan` 与 `serica lex/check` 覆盖；完整行简前端尚不存在 |
| 种子边界 | 证明实现没有扩展种子功能，行数/子集/归因/许可检查通过 | `make seed-audit` 与 `make license` 可复跑；stage0 不是最终自举实现 |
| 编译器表达能力 | 提交行简编译器源文件，并由受约束阶段编译、运行其输出 | 缺失 |

当前可复跑的种子边界检查：`make stage0`、`make test-p0b-scope`、`build/stage0/serica check examples/p0b-window.serica`。这些证明 P0b 入口与 P1b 拒绝边界，不构成 P1b 硬门。完整 P1b 通过命令须在合规行简实现路线确立后建立。

**阶段出口：** 上表所有硬门有可运行的行简实现和成功/失败证据后，才进入 P2b。不得将现有静态子集或 Go 种子扩展标成 P1b 完成。

## P2b：第一次自举

**目标：** 以受限 stage0 编译完全由行简编写的编译器，生成 stage1。stage1 是第一个由种子产出的自举编译器；不能把“stage0 能运行”或“有 stage1 文件”称为自举通过。

| 硬门 | 验收接口（尚未实现） | 状态 |
|---|---|---|
| 编译器源实现位于 `compiler/`，全部为 `.serica`；运行时在 `runtime/`，标准库在 `stdlib/` | 源码审计、许可审计、`make stage1` | 未开始 |
| stage0 能编译该源并得到可运行 stage1 | `make stage0 && make stage1`；运行 `build/stage1/serica --version` 与 hello/编译器回归样例 | 未开始 |
| stage1 与 stage0 对编译器自举输入的行为一致 | `make test` + 固定 golden/诊断/产物检查；测试集合需随实现建立 | 未开始 |
| 没有借用、转译或透传其他语言编译器/运行时生成行简产物 | `./tools/check-independence source`、依赖/符号审计和产物检查 | 未开始 |

stage1 只证明第一次自举链路启动；完整自举证明在 P3b。

## P3b：不动点并删除种子

**目标：** stage1 编译自身得到 stage2，stage2 编译自身得到 stage3；固定源码/构建根和构建标识，归一化后四段逐字节一致，然后删除整个 `bootstrap/`。

| 硬门 | 验收接口（尚未实现） | 状态 |
|---|---|---|
| 构建 stage2、stage3 | `make stage2 && make stage3` | 未开始 |
| 四段归一化逐字节相等 | `make verify`；比较 `.text`、`.rodata`、重定位表、导入符号表，固定 `SOURCE_DATE_EPOCH=0`、`SERICA_BUILD_ID=0`，记录归一化哈希 | 未开始 |
| 删除种子后构建仍通过 | 将 `bootstrap/` 隐藏/移除后 `make clean all`，运行 `--version` 与 hello 示例；手册附录 K.5 | 未开始 |
| 没有种子语言产物特征 | 对所有产物运行源码、链接、符号、构建和环境级独立性检查 | 未开始 |

种子删除是硬门，不可延后或用归档替代。通过 P3b 后，`bootstrap/` 清空，stage0/Go 工具不再作为产品构建依赖。

## P4b：工具链自举

**目标：** 格式化器、包管理器和 LSP 全部以行简重写；工具输出仍为可读源码和可审查诊断，依赖许可进入登记表。

| 工具/硬门 | 验收接口（尚未实现） | 状态 |
|---|---|---|
| `serica fmt` | 格式化幂等；`serica fmt --check` 对 NFC/标点/冻结语法作机器检查；比较格式前后 AST/语义等价 | 未开始 |
| `serica` 包管理子命令 | `serica add/remove/update/list`；锁文件、版本解析、哈希和许可证门禁有离线回归样例 | 未开始 |
| LSP | `initialize`、诊断、跳转/补全等约定能力的协议测试与编辑器实测；实现源码为行简 | 未开始 |
| 单一检查实现 | P4b 接管后归档并删除 Go punct-scan，不允许两套事实来源 | 未开始 |
| 工具许可/独立性 | `REUSE`、依赖登记、断网构建、源码/链接/符号检查 | 未开始 |

P4b 不参与 stage2/stage3 自举判断，但“工具已重写”的硬门须逐个有产物和回归证据。

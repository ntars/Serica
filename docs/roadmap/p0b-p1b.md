# P0b → P1b 自动推进清单

依据《行简 Serica 开发手册》八、3.7、4.6、附录 G 与 K。依赖就绪后按顺序推进；P0b 硬验收通过后才开始 P1b。本清单区分硬验收门和后续完善项。

## 当前基线

- 当前阶段：P1b 进行中；P0b 硬验收于 2026-11-20 在本机 macOS 27.0.1 / arm64 通过。
- stage0：Go 1.27.4 词法器、记录值 AST/解析器、窗口字段语义检查、`lex`、`check`、`build`；直接写出 macOS arm64 Mach-O。
- P0b 窗口通过登记的系统 AppKit、Foundation、Objective-C runtime 和系统 `codesign`。种子不调用 C 编译器、汇编器或链接器。
- P1b 已实现字符串常量拼接、切片、相等比较与常量分支，以及有符号 64 位整数常量算术和 `bitAnd`/`bitOr`/`bitXor`；均在 stage0 编译期求值。
- 原型只作为 3.8 证据归档，不得演进或复制到活动种子。
- 活动种子受 5000 行上限、Go 子集、逐行归因与 P3b 删除门槛约束。

### P0b-04 最小运行时与窗口 — 完成

## P1b：达到可写编译器的语言表达力 — 进行中

### P1b-01 字符串表示与拼接 — 完成

- [x] 表达式 AST 支持字符串字面量的左结合 ASCII `+`。
- [x] 语义层仅接受字符串与字符串拼接；stage0 编译期求值后传入产物数据。
- [x] `examples/p1b-string-concat.serica` 检查/构建通过；Mach-O 产物含拼接后的“点击这里编辑中文”。决策见 D-0015。
- [ ] 字符串运行时表示、可变变量与运行时引用仍未实现；D-0020 加入的不可变常量引用仍在编译期求值。

### P1b-02 字符串切片 — 常量子集完成

- [x] 支持英文标准库名 `substring（文本，起点，终点）`，复用冻结的全角括号与逗号。
- [x] 固定 Unicode 码位零起始、左闭右开语义；非整数、参数数量错误与越界会给语义诊断。
- [x] `examples/p1b-string-slice.serica` 检查/构建通过；`examples/diagnostics/` 的参数数量、类型和越界样例分别返回预期诊断。Mach-O 产物含“语言表可运行”。决策见 D-0016。
- [ ] 运行时字符串、变量索引、grapheme cluster（用户感知字符）语义仍未实现。

### P1b-03 字符串比较与常量分支 — 完成

- [x] `equals（左侧文本，右侧文本）` 比较码位序列；`ifElse（条件，真值，假值）` 暂只接受 `equals` 条件。
- [x] 编译期检查两个分支并选出字符串结果；不执行隐式 Unicode 规范化。
- [x] `examples/p1b-string-equality.serica` 覆盖相等与不相等两个分支，构建结果“切片与相等通过，反例分支通过”写入 Mach-O。决策见 D-0017。
- [ ] 可变变量、运行时布尔值、逻辑组合、通用条件语句与惰性分支仍未实现；当前可引用的只有编译期常量。

### P1b-04 整数常量加法 — 基础子集完成（由 P1b-07 扩展）

- [x] 索引表达式支持 64 位整数常量通过 ASCII `+` 左结合求和；D-0021 扩展了有符号范围与算术运算。
- [x] 加法溢出与非整数项产生语义诊断；溢出见 `examples/diagnostics/p1b-index-overflow.serica`。索引最终仍受切片范围约束。
- [x] `examples/p1b-string-slice.serica` 用 `1+1` 与 `2+3` 算出 `substring` 索引，构建结果正确。决策见 D-0018。
- [x] 有符号常量扩展见 P1b-07 与 D-0021；整数仍在编译期求值，不代表运行时整数。

### P1b-05 常量位运算 — 子集完成

- [x] 有符号整数常量表达式支持二元 `bitAnd`、`bitOr`、`bitXor`，按 64 位补码位模式求值，并允许与整数算术组合；结果可供切片索引使用。
- [x] `examples/p1b-bitwise.serica` 联合使用三种运算生成切片索引；产物包含“语言表位运算通过”。
- [x] `examples/diagnostics/p1b-bitwise-arity.serica` 返回 `S-3021` 非零诊断。
- [ ] 运算仍仅对编译期常量求值；运行时整数和可变整数字段仍未实现。决策见 D-0019、D-0021。

### P1b-06 不可变常量绑定与引用 — 编译期子集

- [x] 支持 `常量 中文名=表达式。`，声明位于唯一的 `窗口` 根绑定之前；常量名以中文汉字开头。
- [x] 字符串与有符号 64 位整数常量按表达式推断类型；引用可用于拼接、切片、比较、分支、算术和位函数。
- [x] 仅允许引用此前声明的常量；重复名、前向/未定义引用和混合类型加法分别产生诊断。
- [x] `examples/p1b-constants.serica` 将字符串、整数及位函数常量组合进窗口文本；Mach-O 产物含“语言表可解析”。决策见 D-0020。
- [ ] 常量仍由 stage0 编译期求值；可变绑定、函数局部作用域与运行时存储仍未实现。

### P1b-07 有符号整数常量算术 — 编译期子集完成

- [x] 支持有符号 64 位边界、一元负号、全角括号分组、二元加减乘除；乘除优先于加减，同级左结合，除法向零截断。
- [x] 加减乘除和取负均检查溢出；除零返回 `S-3024`，溢出返回 `S-3018`，类型不匹配返回 `S-3023`。
- [x] 位函数按有符号 64 位补码位模式运算；`substring` 对最终负索引仍报范围诊断。
- [x] `examples/p1b-integer-arithmetic.serica` 构建结果包含“力，整数运算通过”；五个负例分别验证乘法溢出、除零、除法溢出、取负溢出和类型错误。决策见 D-0021。
- [ ] 取余、移位与运行时整数运算仍未实现。

### P1b 阶段门 — 未通过

- [ ] 字符串、位运算、容器、IO 与模块达到手册第八节要求的语言表达力。
- [ ] 每项能力均有可运行正例、机器可查结果和关键错误诊断，记录在零知识检查表。
- [ ] 上述条件全部通过后才离开 P1b 并启动 P2b；当前常量子集不构成阶段出口。

### 后续基础能力

- [ ] 将源码 NFC 规则纳入行简前端；先明确不把 NFKC 归一化混入编译。
- [ ] 字符串运行时表示、可变变量引用与运行时比较；目前只有编译期常量绑定。
- [ ] 运行时整数、取余与移位；当前算术和位运算仍只支持编译期常量。
- [ ] 动态数组、映射、迭代和更新规则。
- [ ] 文件/进程 IO、错误返回与错误传播。
- [ ] 模块导入、名称解析与可重复构建顺序。
- [ ] 用行简代码实现编译器前端/后端基础；明确自举输入与 stage1 产物。
- [ ] 达到“行简能表达并开始实现自身编译器”的出口后，另列 P2b 自举任务。

# P0b → P1b 详细实施与历史验收记录

> P0b–P6b 当前总状态以 [全阶段清单](p0b-p6b.md) 为准。本文保留早期实施记录；D-0025 曾撤出 P1b 种子实现，随后所有者以 D-0026 授权临时自举桥。D-0027–D-0115 记录原生整数、控制流、数组、UTF-8 文本、入口能力、结果、文件与参数输入、真实整数调用帧、整数及编译期文本结果 ABI、参数文本文件路径、块体函数运行时整数循环、嵌套控制、循环局部变量及提前返回子门，但不代表 P1b 阶段门通过。

以下内容保留早期阶段计划与证据；当前实现状态和执行顺序以 D-0026 与 [P0b–P6b 全阶段清单](p0b-p6b.md) 为准。P1b 正在进行，阶段门尚未通过。

## 当前基线

- 当前 stage0：Go 1.27.4 词法器、窗口/控制台根记录解析、编译期常量/表达式/数组、静态模块闭包与函数、整数变量/运行时动态整数数组、有符号 64 位整数键值哈希映射、整数运算/嵌套控制流（含凡循环内跳出/继续），以及最多 63 输入字节的直接 `readText（）` 输出和最多 16 MiB−1 字节内容的动态映射文本变量；控制台入口以 `能力=array（『stdout』，『stdin』）` 声明 IO 能力，缺失能力在编译期拒绝；函数内 `stdin`、`filesystem.read`、`filesystem.write`、`array.write`、`map.write` 与 `args` 效果由函数签名分别声明，并要求每层调用方继续声明且由根能力复核；控制台可按 `args` 能力读取参数计数及 0 至 255 编译期或运行时整数下标的 UTF-8 参数字符串，参数文本可输出、复制到动态文本变量或文本数组、参与码位长度，也可未经存储直接进入拼接、切片、比较和成功结果载荷。非递归函数和带效果函数以有界 AST 展开支持嵌套调用和模块导入，并可用块体局部变量、局部赋值及返回分支；含凡的无效果整数块体函数保留为带局部状态槽的真实 ARM64 运行时函数，循环、分支和嵌套循环可按到达点声明块作用域整数局部变量并在每轮重新初始化，并可在运行时条件命中时提前返回整数；无效果且构成递归环的纯整数函数也保留为真实 ARM64 运行时函数，以 `x0` 至 `x7` 传参、`x0` 返回，具有独立栈帧并直接 `BL` 调用。无效果整数块体运行时函数还可通过相邻指针/长度寄存器接收只读 UTF-8 文本参数，在最多八槽展平预算内完成 `textLength` 与六种相等/排序比较，并可把参数或受支持的拼接/切片结果复制到函数顶层文本局部；副本拥有独立映射、长度和容量槽，统一返回收束点清理。文本局部可转交给根输出。嵌套消费、容器逃逸、文本/容器/结果载荷/效果函数递归、作用域逃逸及未授权数组/映射变更/其他 IO 仍被拒绝。静态/运行时 `textLength（文本）` 按 Unicode 标量值计长；切片可从直接 readText（）、已初始化文本变量、动态文本数组 arrayGet 或受限拼接取源，并可写回动态文本变量，范围仍限 0–63 码位（最多 252 UTF-8 字节），已初始化变量、直接 `readText（）` 及动态文本数组 `arrayGet` 的单层切片结果均可作为 `textConcat` 操作数；动态 `textConcat` 可嵌套至五层，中间结果限 63 字节；`equals`/`notEquals` 条件支持运行时文本变量、`readText`、五层拼接、受支持源切片和动态文本数组元素，并可与编译期字符串混合；`<`、`<=`、`>`、`>=` 条件也能使用这些运行时文本操作数并与静态字符串比较，按 UTF-8 字节顺序排序且不归一化；根输出另限 63 字节；`lex`、`check`、`build` 直接写出 macOS arm64 Mach-O。
- P0b 窗口通过登记的系统 AppKit、Foundation、Objective-C runtime 和系统 `codesign`。种子不调用 C 编译器、汇编器或链接器。
- `make test-p1b-static`、`make test-p1b-modules` 与 `make test-p1b-runtime` 分别复验编译期、静态模块和原生输出子门；`readInteger（）` 可写入整数变量及数组；`readText（）` 可直接输出（63 字节上限），或初始化/更新动态映射文本变量（最大内容 16 MiB−1 字节）；变量写回形式的 `textConcat（左，右）` 接受直接 `readText（）`、`substring（readText（），…）`、运行时变量、受限切片和最多 63 字节静态字符串操作数，可生成最多 16 MiB−1 字节并安全写回输入变量，直接根输出仍限 63 字节；`textLength（文本）` 支持变量、直接 `readText（）` 以及受限拼接/切片结果；`equals`/`notEquals` 条件还可比较运行时文本变量、`readText`、最多五层拼接、受支持源的切片和动态文本数组 `arrayGet`，并可与静态字符串混合；比较仍按 UTF-8 字节进行；运行时布尔值可存入标量变量并重新赋值，动态布尔数组可初始化、追加、替换、索引读取和计长；`equals`/`notEquals` 可比较静态布尔表达式和运行时布尔变量/数组元素；数组类型检查拒绝整数/布尔混写，布尔根输出规范为 `1`/`0`，布尔整数运算仍拒绝；`substring` 可切取直接 readText、文本变量、动态文本数组 arrayGet 或一层“文本变量 + 静态文本”拼接结果，索引可为静态或运行时整数并执行边界检查；`textConcat` 操作数也可使用上述切片结果（含动态文本数组元素切片），切片源不继续递归嵌套；运行时文本变量还支持四种 Unicode 码位排序条件，不做归一化，编译期字符串排序条件可参与静态 `ifElse` 和逻辑组合。有界 `成功（整数、编译期文本、直接 readText（）或受支持的 textConcat/substring 结果）`/`失败（1..255）` 结果可存入结果变量、复制和重赋值；整数载荷占双槽，文本载荷另存指针和 UTF-8 字节长度，直接运行时输入使用首次成功时建立并可复用的 16 MiB−1 字节匿名映射，受支持的拼接和切片表达式载荷也写入独立结果缓冲区，结果值还可深复制到普通文本变量或文本数组元素。`是否失败`/`错误码` 可观察状态，`结果值` 对失败结果无 stdout 传播错误码，对成功文本可根输出。容器通用载荷、完整错误恢复/跨函数传播、任意动态文本表达式、通用键值类型及一般 IO 仍未实现。详见 D-0060、D-0078–D-0114。
- 原型只作为 3.8 证据归档，不得演进或复制到活动种子。
- 活动种子为 12289/13200 个掩码代码行、余量 911，物理行参考 12571（`make seed-audit`），C-1 为 5049/12324（41.0%），受 Go 子集、逐行归因与 P3b 删除门槛约束；D-0061 记录首次预算调整，D-0087/D-0101/D-0173/D-0192/D-0208/D-0210/D-0229 记录预算扩额，D-0211 统一按掩码代码行计量，D-0158 将两个非语言检查器迁至 Python 以守住额度。新增 Go 实现前须在同一变更中先压缩或移除已有种子代码并重审归因。D-0155 已开放效果函数运行时文本结果形参的四槽 ABI，D-0157 又开放单层直接结果观察并释放成功文本映射，D-0160/D-0162 补上追加、删除与重命名并同步自编前端，D-0192 开放直接或存储参数文本变量驱动的环境变量名称；D-0210 修复 UTF-8 失败出口的寄存器与栈恢复；D-0226/D-0228 增加目录枚举与受控进程执行；D-0235/D-0236 开放受限整数/文本数组结果载荷；但 P1b 仍缺通用结果/容器载荷、完整跨函数恢复和通用 IO。

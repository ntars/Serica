# 词法符号（T-9 冻结）

符号表以开发手册 1.3 与 T-9 为准。修改任何符号前，先落决策记录。

| 用途 | 符号 | 码位 | NFKC |
|---|---|---|---|
| 语句分隔 | `，` | U+FF0C | 折叠为 `,` |
| 语句终止 | `。` | U+3002 | 恒等 |
| 分组与调用 | `（ ）` | U+FF08 / U+FF09 | 折叠为 `( )` |
| 普通字符串 | `『 』` | U+300E / U+300F | 恒等 |
| 原始字符串 | `「 」` | U+300C / U+300D | 恒等 |
| 转义符 | `\` | U+005C | 恒等 |
| 块界定 | `【 】` | U+3010 / U+3011 | 恒等 |
| 注释起始 | `#` | U+0023 | 恒等 |
| 运算符 | `+ - * / % = < >`（`<<` 与 `>>` 由相邻的 `<`/`>` 组成） | ASCII | 恒等 |

数字及运算符使用 ASCII。源码必须为 NFC；禁止 NFKC 归一化。代码区禁半角 `, ; : ( )`、U+3000、U+200B 至 U+200D、正文中的 U+FEFF、全角字母与全角数字。修复诊断同时报告码位列和显示列；字符串和注释内容不自动改写。

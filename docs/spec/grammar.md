# 行简语法（实现约束快照）

本文记录当前 `bootstrap/` 前端实际接受的语法形态，供规范冻结与实现对照。语法以 [词法符号](lexical.md) 为基础，源码必须符合 NFC 且不得执行 NFKC。本文描述当前实现，不表示 P1b 阶段门已通过。

## 产生式

以下 EBNF 中，终结符使用词法规范中的全角符号；`标识符` 为汉字序列，`整数` 为 ASCII 十进制整数（可带前置 `-`），`文本` 为 `『…』` 或 `「…」` 包裹的 UTF-8 字符序列。

```ebnf
源程序     = { 导入 | 常量绑定 | 函数声明 | 程序入口 | 窗口入口 } ;
导入       = "导入" 文本 "。" ;
常量绑定   = "常量" 标识符 "=" 表达式 "。" ;
函数声明   = "函数" 标识符 "（" [ 标识符 { "，" 标识符 } ] "）"
             [ "能力" "=" 能力列表 ] ( "=" 表达式 | 块 ) "。" ;
程序入口   = "程序" "=" "【" "能力" "=" 能力列表 "，" "输出" "=" 表达式 "】" "。" ;
窗口入口   = "窗口" "=" "【" "标题" "=" 文本 "，" "文本" "=" 文本 "】" "。" ;
能力列表   = "array" "（" 文本 { "，" 文本 } "）" ;
块         = "【" { 语句 } "】" ;
语句       = 变量声明 | 赋值 | 删映射键语句 | 若语句 | 循环语句 | 跳出 | 继续 | 返回 | 表达式 "。" ;
变量声明   = "变量" 标识符 "=" 表达式 "。" ;
赋值       = "赋值" 标识符 "=" 表达式 "。" ;
删映射键   = "删映射键" "（" 表达式 "，" 表达式 "）" "。" ;
若语句     = "若" "（" 表达式 "）" 块 [ "否" 块 ] ;
循环语句   = "凡" "（" 表达式 "）" 块 ;
跳出       = "跳出" "。" ;
继续       = "继续" "。" ;
返回       = "返回" 表达式 "。" ;
表达式     = 逻辑或表达式 ;
逻辑或表达式 = 逻辑与表达式 { "故" 逻辑与表达式 } ;
逻辑与表达式 = 比较表达式 { "且" 比较表达式 } ;
比较表达式 = 移位表达式 { ("==" | "<" | "<=" | ">" | ">=") 移位表达式 } ;
移位表达式 = 加法表达式 { ("<<" | ">>") 加法表达式 } ;
加法表达式 = 乘法表达式 { ("+" | "-") 乘法表达式 } ;
乘法表达式 = 一元表达式 { ("*" | "/" | "%") 一元表达式 } ;
一元表达式 = ["-"] 原子表达式 ;
原子表达式 = 调用 | 记录 | 数组构造 | "（" 表达式 "）" | 标识符 | 整数 | 字符串 ;
调用       = 标识符 "（" [ 表达式 { "，" 表达式 } ] "）" ;
记录       = "【" [ 字段 { "，" 字段 } ] "】" ;
字段       = 标识符 "=" 表达式 ;
数组构造   = "array" "（" 表达式 { "，" 表达式 } "）" ;
字符串     = 『…』 | 「…」 ;
```

`=` 只在记录字段和声明/赋值中使用；比较相等使用 `==`。`!=` 不是词法符号，布尔不等通过 `notEquals（…）` 调用表达。`或` 尚未实现，不能作为逻辑运算符。布尔结果由比较、`equals`、`notEquals` 及逻辑组合产生；记录以 `【字段名=值，…】` 书写；`返回` 只在函数块内出现。

## 约束

- 程序入口必须声明 `能力`；输出所需的 `stdout`、`stdin`、`args`、`filesystem.read`、`filesystem.write`、`array.write`、`map.write` 等能力由语义门逐层检查。
- 函数体可以是表达式或块；块中的局部名称必须唯一，未初始化、逃逸和不可达语句由语义门拒绝。
- 源文件中的注释以 `#` 起至行末；注释与字符串仍受 NFC 检查。
- 具体内建函数的名称、元数、类型与效果由 `docs/spec/modules.md` 和 `compiler/*.serica` 的类型表约束；本文件只规定通用语法形态；当前接受的具体语句关键字还包括 `删映射键`。

## 对照测试

`make test-p1b-parse`、`make test-p1b-program`、`make test-p1b-bind` 与 `make test-p1b-runtime` 分别覆盖表达式树、完整程序、绑定和原生构建/运行路径；规范与实现的逐项一致性仍待 M4 一致性套件验收；本快照按 `bootstrap/parser.go` 的 `parseValue`/`parseLogicalOr`/`parseLogicalAnd`/`parseComparison`/`parseShift`/`parseAdditive`/`parseMultiplicative`/`parseUnary`/`parseAtom`/`parseRecord` 与 `isRuntimeStatementKeyword` 校对，尚不构成规范冻结。

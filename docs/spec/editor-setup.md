# 编辑器设置

源码编码为 UTF-8，换行 LF，缩进为 2 个半角空格。编辑器不得在保存时做 NFKC 归一化。

代码字体需配置 CJK 等宽字体，例如更纱黑体或 Noto Sans Mono CJK；不得依赖拉丁字体的任意 fallback 来对齐中文标识符。显示列按东亚宽度计算。诊断应同时给码位列和显示列。

本机原型环境可用系统字体 `/System/Library/Fonts/Hiragino Sans GB.ttc` 做中文字形渲染验证；该字体不代表最终编辑器的等宽字体选择。
